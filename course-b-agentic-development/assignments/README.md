# Course B Assignments

## 用途

本目录用于放置课程 B 阶段作业说明。MVP 阶段定义作业类型、提交标准和评分原则，教师可据此拆分为课堂作业或课后作业。

## 阶段作业建议

1. Agent 交互记录分析。
2. Context Pack 设计。
3. 规则文件设计说明。
4. Skill 设计说明。
5. MCP Server 设计说明。
6. Agent Team 工作流说明。

## 提交要求

每份作业必须包含：

- 任务背景。
- 使用工具。
- 输入材料。
- AI 输出摘要。
- 人工审查记录。
- 最终结论。
- 风险和复盘。

## 评分原则

助教不只看结果，还要看过程是否可审计。没有测试、没有 diff、没有人工判断的作业不能评为优秀。

## 作业落地方式

教师可从上面的 6 类作业中选择 2-3 个作为阶段作业。每个作业发布时应补充具体项目背景、允许使用的工具、提交截止时间、评分表和 Human Gate 要求；助教批改时优先检查过程证据是否完整。
