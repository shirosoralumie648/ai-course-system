# 第 2 周教师讲稿框架：Claude Code 基础与 Lab 01

## 0-10 分钟：回顾第 1 周

教师话术要点：

- “上节课我们讲了 Task Packet。今天要把任务包真正交给 Coding Agent。”
- “本节课的目标不是看 Claude Code 能不能一次写对，而是看它的计划、修改、测试和 diff 是否可审计。”

课堂提问：

- 一个 Task Packet 至少包含哪些部分？
- 哪些操作必须 Human Gate？
- 为什么不能只写“帮我修一下 bug”？

## 10-25 分钟：Claude Code 是什么

讲解要点：

- Claude Code 是 Coding Agent，不是普通 Chatbot。
- 它可以读取项目、提出计划、修改文件、运行命令。
- 能力越强，越需要规则、边界和验证。

建议板书：

```text
任务输入 -> 计划 -> 人工确认 -> 修改 -> diff -> 测试 -> Review -> 接受/拒绝
```

强调：

- 不要求学生相信 Claude Code。
- 要求学生保存证据并做人工判断。

## 25-40 分钟：教师演示项目读取和失败测试

演示路径：

```text
ai-course-system/course-b-agentic-development/examples/repo-01-small-bugfix/
```

演示命令：

```bash
python -m unittest discover -s tests -v
```

讲解要点：

- 先运行测试，建立基线。
- 失败日志是上下文，不是噪音。
- 学生必须保存初始失败状态。

互动问题：

- 哪些测试失败？
- 失败信息指向什么可能原因？
- 现在是否应该直接改代码？

## 40-60 分钟：给 Claude Code 任务并审查计划

教师演示 Task Packet，包含：

- 项目背景。
- 当前失败现象。
- 允许修改 `src/grade_utils.py`。
- 禁止修改 `tests/`、`solution-notes.md`、教师材料。
- 固定测试命令。
- 先输出计划，等待确认。

讲解要点：

- 计划必须说明拟修改文件。
- 计划必须对应失败测试。
- 如果计划涉及测试修改、依赖修改或大重构，应要求停止。

课堂提问：

- 这个计划是否只改允许文件？
- 它有没有说明测试命令？
- 哪些地方需要人工确认？

## 60-75 分钟：diff 审查

演示命令：

```bash
git diff
```

讲解要点：

- diff 是 Agent 实际做了什么的证据。
- 不要只看 Agent 总结。
- 检查是否修改了禁止文件。
- 检查修改是否与 bug 一一对应。

建议让学生回答：

- 改了哪个函数？
- 是否删除或弱化测试？
- 是否引入无关重构？
- 如果你是 Reviewer，会接受吗？

## 75-90 分钟：运行测试与接受判断

演示固定测试命令：

```bash
python -m unittest discover -s tests -v
```

讲解要点：

- 测试通过是必要证据，但不是唯一证据。
- 测试失败时不能写“完成”。
- 工具不可用或命令不可运行时，要说明原因和风险。

接受判断模板：

```text
我接受 / 不接受本次修改。
原因：
- 修改文件是否在允许范围内：
- 测试结果：
- 是否保留原有行为：
- 是否仍有风险：
```

## 90-115 分钟：学生实操 Lab 01

学生任务：

1. 进入示例项目。
2. 运行初始测试。
3. 保存失败日志。
4. 给 Claude Code 输入任务。
5. 记录计划。
6. 如时间允许，完成修改、diff 和测试。

教师巡视重点：

- 学生是否先运行测试。
- Task Packet 是否包含禁止范围。
- 是否保存 Agent 计划。
- 是否看 diff。
- 是否误看 `solution-notes.md`。

## 115-120 分钟：总结与作业

教师话术要点：

- “Lab 01 的核心不是最终代码，而是可审计流程。”
- “没有失败日志、计划、diff、测试和复盘，就不能证明你完成了 Agentic Development 实验。”

课后提交：

- `lab-01-report.md`。
- 初始失败日志。
- Claude Code 计划和输出摘要。
- Git diff。
- 修复后测试日志。
- 复盘，至少说明 Agent 做对和做错的地方。

常见扣分提醒：

- 不运行测试。
- 修改测试骗过结果。
- 不看 diff。
- 只复制 Agent 输出。
- 工具不可用却伪造记录。
