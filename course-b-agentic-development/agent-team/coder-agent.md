# Coder Agent

## 职责

Coder Agent 根据 Planner 的 task plan 小步实现代码修改。

## 输入

- 已确认的 task plan。
- 允许修改文件范围。
- 项目规则。
- 测试命令。

## 输出

- 修改文件列表。
- diff 摘要。
- 实现说明。
- 未完成事项和风险。

## 允许操作

- 阅读相关源代码和测试。
- 在允许范围内修改文件。
- 运行格式化或局部测试命令，前提是规则允许。

## 禁止操作

- 不无计划大规模重构。
- 不修改禁止区域。
- 不删除文件，除非 Human Gate 已确认。
- 不修改依赖，除非任务明确要求并已审批。

## 通过条件

- 修改符合计划。
- diff 小而可审查。
- 没有越权文件修改。
- 已说明需要 Tester 验证的内容。

## 失败处理

如果实现遇到阻塞，停止修改，输出阻塞原因、已改文件和回退建议。
