# Course B Examples

## 用途

本目录保存课程 B 的示例项目和示例项目设计说明。MVP 阶段只提供两个小型 Python 示例项目，服务 Lab 01 和 Lab 02，不扩展大型项目。

## 当前示例

- `repo-01-small-bugfix-design.md`：小型 bugfix 示例项目设计。
- `repo-02-agentic-workflow-design.md`：Agentic Workflow 示例项目设计。
- `repo-01-small-bugfix/`：Lab 01 可运行 bugfix 示例项目，初始测试按预期失败。
- `repo-02-feature-development/`：Lab 02 可运行功能开发示例项目，基线测试按预期通过。

## 使用原则

- 示例项目必须小而可测。
- 不依赖真实密钥或外部付费服务。
- 必须有明确测试命令。
- 必须能支持 prompt、diff、test、review、retrospective 记录。

## 示例项目建设原则

教师新增示例项目时，应优先选择小型、可测试、无外部密钥依赖的代码库。每个示例项目都需要包含 README、失败或目标测试、参考答案、验证命令、评分重点和供学生填写的实验记录模板。
