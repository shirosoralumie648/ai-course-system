# 示例项目 01：Small Bugfix Repo 设计

## 目的

用于 Lab 01，让学生第一次使用 Claude Code 修复真实 bug。

## 建议技术

- Python 小工具或 JavaScript CLI。
- 自带 3-6 个测试。
- 初始状态包含 2-3 个可定位 bug。

## 示例 bug 类型

- 边界条件错误。
- 输入校验缺失。
- 排序或过滤逻辑错误。

## 必须包含

- README。
- 测试命令。
- 失败测试。
- 不涉及外部服务。
- 不含真实密钥。

## 教学重点

学生要记录失败日志、Agent 分析、计划、diff、测试结果和人工接受理由。

## 教师实现规格

教师实现该示例 repo 时，应同时提供初始分支、参考修复分支、测试日志样例和评分参考。学生只能看到初始分支和实验说明；教师答案用于课后讲评和助教批改，不应在实验开始前公开。
