# 期末项目 Demo Checklist

## 1. 演示前检查

- 仓库能打开。
- README 能说明项目目标。
- 规则文件存在。
- Skill 存在。
- MCP 设计或配置存在。
- 测试或验证脚本能说明如何运行。
- Review 或测试报告存在。
- 没有真实密钥、Token、密码和隐私数据。

## 2. 必须展示的内容

- 项目解决什么问题。
- Agentic Workflow 流程。
- `CLAUDE.md` 或 `AGENTS.md` 的关键规则。
- 至少 1 个 Skill。
- MCP 设计或配置。
- 至少 3 个 Agent / Subagent 角色。
- 一次真实测试或验证记录。
- 一次 Review 或 Human Gate 决策。

## 3. 不建议展示的内容

- 长时间现场安装依赖。
- 未验证的工具命令。
- 真实密钥或账号页面。
- 大段 AI 对话原文。
- 与项目无关的炫技演示。

## 4. 常见翻车点

- 仓库缺关键文件。
- 只展示最终代码，不展示工作流。
- 测试命令现场失败且没有解释。
- Skill 只是普通 Prompt。
- MCP 设计没有安全边界。
- 无法解释 Human Gate。

## 5. 答辩问题清单

1. 你的 Agentic Workflow 中最关键的人工确认点是什么？
2. 你的 Skill 如何防止 Agent 编造测试结果？
3. MCP 工具输出为什么不能默认可信？
4. 如果 Tester 发现测试失败，流程如何回退？
5. 你的规则文件如何限制 Agent 修改范围？
6. 下一版你会优先改进什么？
