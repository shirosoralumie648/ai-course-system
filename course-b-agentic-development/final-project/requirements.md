# 期末项目要求：构建一个 AI 原生软件工程工作流

## 项目目标

学生最终要交付的不只是代码，而是一套可解释、可验证、可审查的 Agentic Workflow。

## 可选方向

- A. 课程项目代码审查 Agent Workflow
- B. Bugfix Agent Workflow
- C. 自动测试生成 Agent Workflow
- D. 文档维护 Agent Workflow
- E. 小型开源项目维护 Agent Workflow
- F. 自定义 MCP 课程助手
- G. 面向某类项目的 Agentic Development 模板包

## 必须交付

1. GitHub 仓库。
2. `README.md`。
3. `CLAUDE.md` 或 `AGENTS.md`。
4. 至少 1 个 Skill。
5. 至少 1 个 MCP 配置或 MCP Server 设计。
6. 至少 3 个 Agent / Subagent 角色设计。
7. 至少 1 个自动化测试或验证脚本。
8. 一份 Agent 工作流说明。
9. 一份代码审查或测试报告。
10. 3-5 分钟演示视频或演示脚本。
11. 期末技术报告。
12. 课程复盘文档。

## 基本要求

- 所有 AI 输出必须经过人工审查。
- 所有测试结果必须真实。
- 不能提交真实 API Key、Token、密码和隐私数据。
- MCP Server 可以是设计文档，不要求 MVP 阶段生产级实现。
- 如果某个功能无法运行，必须说明原因和后续计划。

## 提交方式

- 提交 GitHub 仓库链接。
- 提交最终报告 Markdown。
- 提交演示视频链接或演示脚本。
- 提交 Review 或测试报告。

## 教师准备材料

教师在开题前应提供 2-3 个示例项目方向说明，标明难度、建议工具链、推荐交付物和风险边界。示例项目可以是代码审查工作流、Bugfix 工作流、测试生成工作流或课程 MCP 助手设计，但不得要求学生提交真实密钥或访问未授权外部服务。
