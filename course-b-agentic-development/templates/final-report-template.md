# 期末技术报告模板

> 模板性质：教学模板。用于课程 B 期末项目提交。

## 1. 项目概述

- 项目名称：
- 项目方向：
- 目标用户：
- 解决的问题：

## 2. Agentic Workflow 总览

说明你的工作流如何从需求输入走到交付报告。

## 3. 规则文件设计

- `CLAUDE.md` 或 `AGENTS.md` 的关键规则。
- 允许和禁止行为。
- Human Gate 设计。

## 4. Skill 设计

- Skill 名称。
- 适用场景。
- 输入和输出。
- 检查清单。
- 禁止行为。

## 5. MCP 设计或配置

- 工具或资源。
- 输入输出。
- 风险和审批。
- MVP 阶段未实现的部分要明确说明。

## 6. Agent Team 设计

- Planner。
- Coder。
- Tester。
- Reviewer。
- Human Gate。

## 7. 测试与验证

- 测试命令。
- 测试结果。
- 失败处理。
- 无法测试的原因。

## 8. Code Review 或测试报告

粘贴或链接结构化 Review。

## 9. 演示说明

说明 3-5 分钟演示展示什么，不展示什么。

## 10. 复盘

- Agent 帮助最大的地方。
- Agent 最容易出错的地方。
- 下一版如何改进。
