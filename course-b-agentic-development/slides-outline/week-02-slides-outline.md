# 第 2 周 PPT 大纲：Claude Code 基础与 Lab 01

## Slide 1：标题页

- 核心内容：第 2 讲：Claude Code 基础与 Lab 01。
- 教师讲解要点：本讲进入第一个真实 Coding Agent 实验。
- 是否有互动：否。

## Slide 2：本讲目标

- 核心内容：读项目、给任务、看计划、审查 diff、运行测试、完成 Lab 01。
- 教师讲解要点：强调过程证据。
- 是否有互动：否。

## Slide 3：回顾 Task Packet

- 核心内容：目标、上下文、范围、测试、验收、Human Gate。
- 教师讲解要点：把 Week 01 内容带入 Lab 01。
- 是否有互动：是，学生复述关键项。

## Slide 4：Claude Code 是什么

- 核心内容：面向代码库任务的 Coding Agent。
- 教师讲解要点：能读文件、改文件、跑命令，但必须受控。
- 是否有互动：否。

## Slide 5：Claude Code 工作流

- 核心内容：任务输入 -> 计划 -> 人工确认 -> 修改 -> diff -> 测试 -> Review。
- 教师讲解要点：每一步都要留下证据。
- 是否有互动：否。

## Slide 6：Lab 01 项目说明

- 核心内容：`examples/repo-01-small-bugfix/`；成绩统计函数库。
- 教师讲解要点：这是小型可控 bugfix，不做大项目。
- 是否有互动：否。

## Slide 7：初始测试命令

- 核心内容：`python -m unittest discover -s tests -v`。
- 教师讲解要点：先建立失败基线。
- 是否有互动：是，学生判断为什么先测。

## Slide 8：失败现象

- 核心内容：空列表平均值、60 分及格边界。
- 教师讲解要点：失败日志是上下文。
- 是否有互动：是，学生读失败信息。

## Slide 9：Lab 01 Task Packet

- 核心内容：目标、允许修改、禁止修改、测试命令、工作流程。
- 教师讲解要点：禁止修改测试和参考答案。
- 是否有互动：否。

## Slide 10：如何要求先计划

- 核心内容：先分析失败原因，列出拟修改文件，等待确认。
- 教师讲解要点：计划是 Human Gate 前的检查点。
- 是否有互动：是，学生判断计划是否合理。

## Slide 11：计划审查清单

- 核心内容：是否理解问题；是否只改允许文件；是否跑测试；是否有无关重构。
- 教师讲解要点：不合理计划要拒绝或要求重写。
- 是否有互动：否。

## Slide 12：diff 审查

- 核心内容：`git diff`；文件范围；行为变化；测试是否被改。
- 教师讲解要点：Agent 总结不能替代 diff。
- 是否有互动：是，学生解释 diff。

## Slide 13：测试证据

- 核心内容：初始失败日志、修复后通过日志、失败重试记录。
- 教师讲解要点：未运行测试不能写通过。
- 是否有互动：否。

## Slide 14：接受或拒绝修改

- 核心内容：接受判断模板。
- 教师讲解要点：学生要说明人工判断。
- 是否有互动：是，投票是否接受示例修改。

## Slide 15：工具不可用替代流程

- 核心内容：记录原因、手动修复、保留 diff 和测试、补写 Task Packet。
- 教师讲解要点：不可用不伪造。
- 是否有互动：否。

## Slide 16：solution-notes 风险

- 核心内容：教师参考材料不应提前查看。
- 教师讲解要点：若已查看必须如实记录。
- 是否有互动：否。

## Slide 17：学生实操步骤

- 核心内容：进入项目、运行测试、输入任务、记录计划、审查 diff、运行测试。
- 教师讲解要点：课堂内至少完成前半段。
- 是否有互动：是，学生实操。

## Slide 18：提交物

- 核心内容：实验记录、测试日志、Claude Code 输出摘要、Git diff、复盘。
- 教师讲解要点：缺少过程证据会扣分。
- 是否有互动：否。

## Slide 19：常见问题

- 核心内容：工具不可用、测试被改、Agent 直接修改、测试失败。
- 教师讲解要点：把问题转化为可记录的失败案例。
- 是否有互动：是，学生提问。

## Slide 20：本讲总结

- 核心内容：Claude Code 是可用工具，但必须在任务包和证据链中使用。
- 教师讲解要点：连接下周 Codex 小功能开发。
- 是否有互动：否。
