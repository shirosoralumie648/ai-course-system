# Part 1

## 什么是 API？

* * *

# API 的餐厅比喻

**想象你去餐厅吃饭**：

-   **你**：顾客（你的原型）
-   **厨房**：AI 服务（DeepSeek、Qwen 等）
-   **服务员**：API（应用程序编程接口）

你不能直接冲进厨房喊「给我做个菜」 你得通过服务员点菜（发送请求） 服务员把菜端给你（返回结果）

* * *

# API 的四个核心要素

**1\. API Key（通行证）**

-   证明「这是我在调用」
-   别人拿到你的 Key，就能冒充你并产生费用

**2\. Endpoint（接口地址）**

-   告诉服务器你要访问哪个功能
-   例如：`https://api.deepseek.com/v1/chat/completions`

* * *

# API 的四个核心要素（续）

**3\. 请求内容（Request）**

-   你要 AI 做什么
-   比如：「帮我写一段电商文案」

**4\. 响应结果（Response）**

-   AI 返回的内容
-   成功：返回生成的文字、图片等
-   失败：告诉你哪里错了

* * *

# API 调用的完整流程

**场景：用户点击「生成文案」按钮**

1️⃣ **前端发起请求**（整理数据） 2️⃣ **请求发送到 AI 服务器**（通过互联网） 3️⃣ **AI 服务器处理**（验证密钥、调用模型） 4️⃣ **返回结果**（生成的内容） 5️⃣ **前端展示结果**（用户看到了！）

* * *

# ⚠️ API 密钥安全警告

**API Key 就是你的钱包钥匙！**

**绝对不能做的事**：

-   ❌ 把 Key 发到群聊、论坛
-   ❌ 截图时不打码
-   ❌ 硬编码到代码里并提交 Git
-   ❌ 分享给不信任的人

**正确做法**：

-   ✅ 使用环境变量存储
-   ✅ 添加到 `.gitignore`
-   ✅ 定期更换密钥
-   ✅ 如怀疑泄露，立即重置

## 接入文本生成：DeepSeek

* * *

# 为什么选择 DeepSeek？

**DeepSeek** 是杭州深度求索人工智能公司开发的大语言模型

**小林选它的理由**：

-   **性价比高**：价格比 GPT-4 便宜很多
-   **中文友好**：对中文理解很好
-   **开源模型**：技术透明，社区活跃
-   **性能强劲**：在多项基准测试中接近 GPT-4 水平

**费用**：生成 200 字文案约 0.002 元（不到 1 分钱）

* * *

# 三步接入法

**第 1 步：获取 API Key**

-   访问 [DeepSeek 开放平台](https://platform.deepseek.com/)
-   注册账号并充值 10-20 元
-   创建 API Key

**第 2 步：找到官方调用示例**

-   访问 [API 文档](https://api-docs.deepseek.com/)
-   复制 curl 或 JavaScript 示例

**第 3 步：让 Claude Code 帮你集成**

-   把需求、API Key、官方示例一起告诉 Claude Code

* * *

# 第 1 步：获取 DeepSeek API Key

**操作流程**：

1.  访问 [platform.deepseek.com](https://platform.deepseek.com/)
2.  注册账号并登录
3.  进入「使用管理」页面，充值 10-20 元
4.  点击左侧菜单「API Keys」
5.  点击「Create new API key」
6.  给 Key 起个名字（比如「学习测试」）
7.  复制生成的 Key（格式：`sk-8573341c39fc44315aadc071c53rh7d2`）

⚠️ **重要**：这个 Key 只会显示一次！立即保存

* * *

# 第 2 步：找到官方调用示例

访问 [api-docs.deepseek.com](https://api-docs.deepseek.com/)

**curl 示例**：

```bash
curl https://api.deepseek.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${DEEPSEEK_API_KEY}" \
  -d '{
        "model": "deepseek-chat",
        "messages": [
          {"role": "system", "content": "You are a helpful assistant."},
          {"role": "user", "content": "Hello!"}
        ]
      }'
```

* * *

# 第 3 步：让 Claude Code 集成

**打开 Claude Code，输入**：

```
参考这个调用方法，帮我支持文案生成功能，
可以基于商品信息点击后生成对应抖音电商文案，多种风格。

以下参考资料：
api key：sk-8573341c39fc44315aadc071c53rh7d2
api 请求参考：
[粘贴官方示例]
```

**Claude Code 会自动**：

-   分析你的原型结构
-   添加 API 调用代码
-   处理请求和响应
-   添加错误处理

* * *

# 实际效果：代码自动生成

**Claude Code 会创建**：

1.  **API 调用函数**（`src/api/deepseek.js`）

    -   封装请求逻辑
    -   添加错误处理
2.  **更新组件**（`src/components/ProductDetail.vue`）

    -   添加风格选择器

**方法 3：查看平台消费记录**

-   访问 [DeepSeek 使用管理页面](https://platform.deepseek.com/usage)

# Part 3

## 接入图像理解：Qwen3 VL

* * *

# 为什么需要图像理解？

**小林的问题**：

-   用户可以上传商品图片
-   但文本模型看不懂图片内容
-   生成的文案可能会文不对题

**解决方案**： 使用视觉语言模型（VLM）

* * *

# 什么是 VLM？

**VLM（Vision-Language Model）** = 视觉 + 语言模型

**典型能力**：

-   📸 **图像描述**：「这是一张智能手表的产品图...」
-   🔍 **视觉问答**：「图片中的手表是什么颜色？」→「黑色」
-   📝 **文字提取**：从图片中识别文字（OCR）
-   🎨 **场景理解**：「这张图的拍摄场景是室内...」

**小林的使用场景**： 用户上传图片 → VLM 分析 → 生成准确的商品描述

* * *

# 为什么选择 Qwen3 VL？

**Qwen3 VL** 是阿里云通义千问团队推出的视觉语言模型

**选择理由**：

-   **中文理解好**：对中文提示词理解准确
-   **性价比高**：比国际竞品便宜
-   **速度快**：响应时间短
-   **质量稳定**：在电商场景表现可靠

* * *

# 通过 SiliconFlow 接入

**什么是 SiliconFlow（硅基流动）？**

-   国内知名的 AI 模型聚合平台
-   一个平台集成多种模型
-   统一的 API 格式（兼容 OpenAI）
-   按需付费，价格透明

**就像「AI 模型超市」** 不用分别去每个模型的官网注册

* * *

# 接入步骤

**第 1 步**：注册并获取 API Key

-   访问 [cloud.siliconflow.cn](https://cloud.siliconflow.cn/)
-   注册账号并充值 10 元

**第 2 步**：选择模型

-   筛选「视觉」标签

**第 3 步**：让 Claude Code 集成

-   提供 API Key、模型名称、官方示例

* * *

# 实际效果：图像分析

这是一款现代智能手表，采用圆形表盘设计，

## 接入图像生成：Seedream

* * *

# 什么是图像生成模型？

**图像生成模型** 可以根据文字描述创造全新的图片

**典型应用**：

-   📱 **电商主图**：「一款智能手表放在木质桌面上...」
-   🎭 **营销海报**：「双十一促销海报，红色主题...」
-   🖼️ **概念图**：快速出设计稿、配图
-   🎬 **社交媒体**：生成头像、表情包、配图

**小林的使用场景**： 输入「为这款智能手表生成一张电商海报」→ AI 生成专业的产品图

* * *

# 为什么选择 Seedream？

**Seedream 4.5** 是字节跳动推出的图像生成模型

**选择理由**：

-   **国内网络稳定**：访问速度快，延迟低
-   **中文优化**：对中文提示词理解准确
-   **速度快**：生成效率高
-   **质量高**：支持 4K 高清图像
-   **功能全面**：文生图 + 图生图

* * *

# 通过火山引擎接入

**第 1 步**：注册并充值

-   访问 [火山引擎 Seedream 页面](https://www.volcengine.com/experience/ark?launch=seedream)
-   登录并完成实名认证
-   充值 1-10 元用于测试

**第 2 步**：创建 API Key

-   进入控制台，找到「API 访问」
-   创建新的 API Key

**第 3 步**：让 Claude Code 集成

-   提供 API Key、模型名称、官方示例

* * *

# 实际效果：图像生成

**两种模式**：

**文生图**：纯文字描述生成图片

```javascript
generateProductPoster(
  '一款黑色智能手表放在木质桌面上，柔和的自然光，简约现代风格，4K高清'
)
```

**图生图**：基于参考图 + 文字描述生成新图片

```javascript
generateProductPoster(
  '将商品放在电商海报背景中，添加促销标签和文字',
  ['产品图URL', '模板图URL']
)
```

* * *

# ⚠️ 重要提示

**生成图片时记得设置**：

```javascript
{
  "watermark": false,  // 不添加水印
  "stream": false      // 不使用流式响应
}
```

**否则可能**：

-   生成失败
-   图片带水印

* * *

# 调试技巧

**小林的经验**：

**1\. 显示完整错误信息**

```
不要只显示「图片生成失败」，
每次都显示完整的失败原因！
```

**2\. 遇到问题时重启项目**

```
请你重启这个项目
```

**3\. 检查参数格式**

-   图片 URL 格式是否正确
-   prompt 是否太短或太长
-   参考图数量是否超限（最多 3 张）

## 如何找到更好的 AI 模型？

* * *

# LMArena - 模型竞技场

**网站**：[lmarena.ai](https://lmarena.ai/)

**工作原理**：

1.  你输入一个问题
2.  平台同时调用两个匿名模型
3.  你投票选择更好的回答
4.  根据投票统计模型排名

**为什么有用？**

-   真实用户投票，不是实验室跑分
-   盲测避免品牌偏见
-   能看到「大家觉得哪个更好用」

* * *

# Artificial Analysis - 参数对比

**网站**：[artificialanalysis.ai](https://artificialanalysis.ai/)

**对比维度**：

-   **Quality（质量）**：模型输出质量评分
-   **Price（价格）**：每百万 tokens 的成本
-   **Latency（延迟）**：响应速度
-   **Throughput（吞吐）**：并发处理能力

**使用建议**： 不要凭感觉争论「哪个更强」 用同一组输入测试 2-3 个模型，结合榜单与价格做决定
