# 16 周教学日历：产品原型与 Claude Code 高级技能

> **给你的使用说明：** 每周按顺序完成"课堂内容 → 课堂任务 → 作业"。前 8 周把一个产品原型做出来，后 8 周把 Claude Code 的协作方式变成可复用流程。

## 小林的故事

> 小林是新闻传播专业大三学生，不会写代码，但想做一个能真正演示的小工具。她先用 AI IDE 和 Claude Code 降低入门门槛，再用产品方法找到真实需求、搭原型、接 AI。后半程，她继续学习 Workflow、Skills、MCP、Superpowers、Spec Coding、长运行任务和 Agent Teams，把"让 AI 帮忙"升级成"让 AI 按流程协作"。
