### 1.2 什么是 Claude Code？（8 分钟）

**[展示 PPT：Claude Code 介绍]**

Claude Code 是 Anthropic 官方推出的 AI 原生编程工具。它将大型语言模型的能力直接集成到终端中。

让我给大家讲讲它的四个核心特点：

**1. 终端原生**

不需要切换到浏览器或 IDE，直接在命令行里与 AI 对话。这意味着你可以无缝集成 Git、npm、测试等工具。

**[演示操作]**
看，我在终端里输入 `claude`，就能启动 Claude Code。然后我可以直接对它说：「运行测试」，它会执行 `npm test` 并分析结果。

**2. 项目记忆**

通过 `CLAUDE.md` 文件，Claude Code 能记住项目信息。你不需要每次都重新解释：「这是一个 React 项目，用 TypeScript，状态管理用 Zustand...」

它会自己记住。

**3. 完整工作流**

从需求分析到代码实现，从测试调试到 Git 提交，从文档编写到代码审查——Claude Code 能覆盖整个开发流程。

**4. 自然语言驱动**

这一点和 Bolt 一样。你用人话描述需求，AI 自动编写代码。支持多轮对话，能理解上下文，记住之前的讨论。

### 4.2 技巧 1：双击 Esc 回退对话（3 分钟）

**[展示 PPT：技巧 1]**

**快捷键：** 连续按两次 `Esc`

**作用：** 撤销上一轮对话，回到之前的状态。

**使用场景：**
- 不小心发了错误的指令
- 对 Claude 的回答不满意，想换个方式提问
- 对话进行太多轮，上下文混乱了

**[演示操作]**

让我演示一下。我先问 Claude 一个问题：

```
帮我写一个排序算法
```

Claude 开始生成代码了。但我突然意识到，我想要的是冒泡排序，不是快速排序。

这时候，我连续按两次 `Esc`。

看，对话回退了。现在我可以重新提问：

```
帮我写一个冒泡排序算法
```

**重要提醒：**

双击 Esc 只回退**对话状态**，不会撤销**文件修改**。

如果 Claude 已经修改了文件，需要用 Git 恢复：
```bash
git checkout -- filename.js
```

建议：在让 Claude 做大改动前，先提交当前工作。

### 4.3 技巧 2-5：文件操作和规划（10 分钟）

**[展示 PPT：技巧 2]**

**技巧 2：@ 引用文件**

**符号：** `@`

**作用：** 精准指定 Claude 要读取的文件或目录。

**[演示操作]**

假设我有一个 `src/utils.ts` 文件，我想让 Claude 解释它。

❌ **不好的方式：**
```
解释 src/utils.ts 这个文件
```

✅ **好的方式：**
```
@src/utils.ts 解释这个文件
```

输入 `@` 后按 `Tab` 键，Claude 会显示当前目录的文件列表，可以用方向键选择。

**高级用法：**
```
# 对比两个文件
@src/components/OldButton.tsx @src/components/NewButton.tsx 
对比这两个组件的差异

# 引用整个目录
@src/components/ 总结一下这个目录下的所有组件
```

**为什么要用 @？**
- 更精准：Claude 知道你要的是哪个文件
- 省 Token：避免 Claude 读取不相关的文件
- 更快速：直接定位，不需要搜索

**最佳实践：**
超过 30 分钟的任务，先用 `/plan`

**技巧 5：/init 自动生成配置**

**命令：** `/init`

**作用：** 自动扫描项目，生成 `CLAUDE.md` 配置文件。

**[演示操作]**

**为什么重要：**
