## 实验目标

完成本实验后，你应该能够：

1. 说明 Superpowers 这类流程技能为什么能降低 AI 编程风险。
2. 在一个小任务中加入需求澄清、计划、执行、验证和复盘环节。
3. 识别 Claude Code 在什么时候容易跳过流程。
4. 用检查清单证明你没有只依赖 AI 的口头结论。

## 实验任务

选择你的产品原型中的一个小型迭代，用 Superpowers 思路约束整个过程。

可选迭代：

| 迭代类型 | 示例 |
|---|---|
| 可用性改进 | 给空状态、错误状态、加载状态补充文案 |
| 页面整理 | 把一个页面的信息层级调整得更清楚 |
| 验证补齐 | 为现有功能补充人工验收清单 |
| 小功能 | 增加一个设置项、筛选项或反馈入口 |

如果你的环境没有安装 Superpowers，也可以用“模拟流程纪律”的方式完成：你必须明确写出本次使用了哪些流程规则。

## 操作步骤

### 第一步：选择小迭代并限定范围

写下本次迭代卡片：

```markdown
迭代名称：
用户问题：
本次只做：
本次不做：
预计验证方式：
```

范围要小，避免“优化整个项目”。

### 第二步：做需求澄清

在动手前，向 Claude Code 提出澄清要求：

```text
在修改任何文件前，请先帮我澄清这个需求：
1. 目标用户是谁？
2. 用户当前遇到什么问题？
3. 本次最小可交付结果是什么？
4. 有哪些可能误解的地方？
5. 哪些内容需要我人工确认？
```

保存 Claude Code 的回答，并写出你最终确认的版本。

### 第三步：写计划清单

让 Claude Code 先写计划，不要直接执行：

```text
请根据已确认需求，写一个不超过 6 步的执行计划。
每一步都要包含：要做什么、涉及哪些文件、如何验证。
现在不要修改文件。
```

把计划改成检查清单：

```markdown
- [ ] 阅读相关页面和组件
- [ ] 找到相似写法
- [ ] 修改目标页面
- [ ] 运行或说明验证方式
- [ ] 人工检查用户路径
- [ ] 写复盘记录
```

### 第四步：按清单执行并记录偏差

每执行一步，记录：

- 实际做了什么
- 是否和计划一致
- 如果偏离计划，为什么偏离
- 是否需要人工确认

不要把偏差隐藏起来。流程纪律的价值就是让偏差可见。

### 第五步：完成验证门禁

在宣布完成前，必须做验证门禁。至少选择 3 项：

| 验证项 | 证据 |
|---|---|
| 需求逐条对照 | 勾选表 |
| 页面人工检查 | 截图、录屏或文字记录 |
| 命令验证 | 命令和输出摘要 |
| 同伴试用 | 同学反馈记录 |
| 风险复查 | 哪些问题仍未解决 |

验证记录要写清楚“通过”“未通过”或“无法验证”。

### 第六步：复盘流程纪律

回答以下问题：

1. Claude Code 有没有试图过早开始修改？你如何阻止？
2. Claude Code 有没有过早说完成？你用了什么证据确认？
3. 哪一步最有价值？
4. 哪一步显得过重，可以在下次简化？
5. 这套流程适合哪些任务，不适合哪些任务？

## 提交要求

1. 小迭代卡片。
2. 需求澄清记录。
3. 计划清单。
4. 执行记录，至少 4 条。
5. 偏差记录，允许写“无偏差”，但要说明依据。
6. 验证门禁证据，至少 3 项。
7. 流程纪律复盘。

## 验收标准

- 任务范围清楚，能在一次实验中完成。
- 修改前有需求澄清和计划记录。
- 执行过程能看出按清单推进。
- 验证门禁不是一句“已完成”，而是有证据。
- 复盘能识别流程纪律的收益和成本。

## 常见问题

### 这是不是太麻烦了？

对很小的任务可能确实偏重。本实验的目的就是让你亲自感受流程成本，再学会判断什么时候需要完整流程。

### 我没有安装 Superpowers 怎么办？

可以模拟使用：把 brainstorming、writing plans、verification before completion 等规则写成自己的流程要求，并按要求执行。

### Claude Code 没有跳过流程，我怎么写偏差？

写“无明显偏差”，并说明你用了哪些提示语和检查点让它保持流程。

## 评分标准

| 维度 | 分值 | 说明 |
|---|---:|---|
| 迭代范围 | 15 分 | 小而明确，有边界 |
| 需求澄清 | 20 分 | 修改前识别用户、问题和确认点 |
| 计划清单 | 15 分 | 不超过 6 步，每步可验证 |
| 执行记录 | 20 分 | 有过程、有偏差、有人工判断 |
| 验证门禁 | 20 分 | 至少 3 项证据 |
| 复盘 | 10 分 | 能讨论流程纪律的适用边界 |
