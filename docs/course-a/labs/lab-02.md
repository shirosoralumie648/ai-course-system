## 实验目标

- 熟悉 AI IDE 的基本区域：文件树、编辑器、AI 对话、终端、预览。
- 理解「本地项目」是一个由多个文件组成的文件夹。
- 能启动一个本地网页程序，并用浏览器访问。
- 学会把终端报错复制给 AI，请它解释和修复。

## 实验任务

在自己的电脑上创建一个小型网页程序，主题自选，但必须与「个人学习或生活效率」有关。程序不要求复杂，可以是课程计时器、待办清单、单词卡片、读书记录、运动打卡等。

项目至少包含：

- 一个清晰标题。
- 一个输入区域或按钮。
- 一个会变化的结果区域。
- 至少一处你用 AI 迭代修改过的界面或文案。

## 操作步骤

### 第一步：创建本地项目文件夹

在电脑上新建一个容易找到的文件夹，例如：

```text
ai-course-labs/
  week-02-first-program/
```

不要把项目放在系统目录或下载临时目录。打开 AI IDE 后，用「打开文件夹」功能打开这个项目目录。

### 第二步：截取 AI IDE 工作区

在生成代码前，先截图标记你的工作区。截图中应能看到：

- 左侧文件树。
- 中间编辑区域。
- AI 对话区域或侧边栏。
- 下方终端区域。

在实验报告中用文字说明每个区域的用途。

### 第三步：让 AI 创建第一个程序

向 AI IDE 输入一段具体需求。示例：

```text
请在当前文件夹中创建一个最简单的网页应用，主题是「学习计时器」。
要求：
1. 页面显示标题「我的 25 分钟学习计时器」
2. 有开始、暂停、重置三个按钮
3. 显示剩余时间
4. 有一个输入框，可以写下本轮学习目标
5. 页面样式简洁，适合非计算机专业学生使用
6. 请告诉我如何在本地运行
```

如果 AI 建议使用 Vite、React、Vue 或纯 HTML，都可以接受。不要强行追求复杂框架，能运行最重要。

### 第四步：启动本地服务

按照 AI IDE 给出的命令运行项目。常见命令包括：

```bash
npm install
npm run dev
```

或直接打开：

```text
index.html
```

保存终端输出，特别是本地访问地址，例如 `http://localhost:5173/`。

### 第五步：处理一次真实问题

如果你遇到报错，把完整报错复制给 AI，让它解释并修复。如果没有自然报错，请主动做一次小迭代，例如：

```text
当前页面能运行，但按钮太小。请把按钮变大一些，增加 hover 效果，并保证手机屏幕也能正常显示。
```

记录修改前后对比。

### 第六步：整理文件清单和运行证据

在报告中列出项目文件，例如：

```text
week-02-first-program/
  package.json
  index.html
  src/
    main.js
    style.css
```

如果你的项目结构不同，按实际情况写。重点是证明你知道项目文件在哪里。

## 验收标准

- 项目文件属于你自己的本地文件夹，不依赖课程样例项目。
- 老师能根据你的说明找到入口文件或运行命令。
- 页面能正常打开，并且至少有一个可交互元素。
- 终端日志或浏览器截图能证明程序在本地运行。
- 遇到问题时能用普通语言向 AI 描述并完成一次修改。

## 常见问题

**Q：我没有安装 Node.js 怎么办？**
A：可以先做纯 HTML 版本，让 AI 生成 `index.html`、`style.css`、`script.js`，直接用浏览器打开。

**Q：终端显示很多英文，看不懂怎么办？**
A：复制完整输出给 AI，要求它用中文解释「哪一句是错误、我下一步该做什么」。

**Q：AI 生成了很多文件，我要全部理解吗？**
A：本周只要求知道入口文件、运行命令、主要页面在哪里，不要求逐行解释代码。
