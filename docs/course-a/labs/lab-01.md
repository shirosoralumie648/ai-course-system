## 实验任务

选择一个你专业课的真实任务，分别用"模糊 Prompt"和"结构化 Prompt"让 AI 完成，对比输出质量。

### 第一步：选题

从以下场景中选一个，或自定义一个专业任务：

| 专业方向 | 示例任务 |
|---|---|
| 新闻传播 | 为"大学生心理健康"写一份调研提纲 |
| 商科 | 分析"某奶茶品牌为什么能成功" |
| 教育 | 为"小学三年级数学"设计一个课堂活动 |
| 法学 | 解释"民法典中隐私权的主要内容" |
| 医学 | 为"糖尿病患者"写一份饮食建议 |
| 外语 | 将一段中文商务邮件翻译成英文并润色 |
| 设计 | 为"校园咖啡馆"写一份品牌定位说明 |

### 第二步：写模糊 Prompt

直接用日常语言提问，不要加任何结构：

> 帮我写一个关于大学生心理健康的调研提纲

### 第三步：用结构化 Prompt 改写

按以下结构重写你的 Prompt：

- **角色**：你希望 AI 扮演什么角色？
- **任务**：具体要做什么？
- **背景**：这个任务的背景是什么？
- **限制**：有什么不能做或必须做的？
- **格式**：输出长什么样？

### 第四步：对比分析

把两份 AI 输出放在一起打分（1-5 分）：

| 维度 | 模糊 Prompt 输出 | 结构化 Prompt 输出 |
|---|---|---|
| 任务完成度 | | |
| 内容准确性 | | |
| 结构清晰度 | | |
| 是否可直接使用 | | |
| 需要人工修订的程度 | | |

## 提交要求

1. 选题说明
2. 模糊 Prompt 原文
3. 结构化 Prompt 原文
4. 两份 AI 输出原文（不修改）
5. 对比分析表
6. 人工修订（选更好的输出做修订，标注改了什么、为什么改）
7. 复盘

## 评分标准

| 维度 | 分值 | 说明 |
|---|---|---|
| Prompt 改写质量 | 20 分 | 是否包含角色、任务、背景、限制、格式 |
| 对比分析深度 | 25 分 | 是否从多个维度对比，有具体证据 |
| 人工修订质量 | 25 分 | 修订是否有明确理由 |
| 复盘反思 | 20 分 | 是否有真实收获 |
| 提交完整性 | 10 分 | 7 项是否齐全 |

## 常见错误

- 只说"结构化 Prompt 更好"，但不分析具体好在哪里
- 对比时只看长度，不看内容质量
- 人工修订只是改了格式，没改内容
- 复盘写"我学到了 Prompt 很重要"，但没有具体收获
