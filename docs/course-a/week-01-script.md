# Week 01 讲稿：游戏热身 - 消除编程畏惧

**课程时长**：90 分钟  
**授课对象**：非技术背景学生（如小林）  
**教学目标**：让学生完成第一个 AI 生成的游戏，建立信心

---

## 课前准备（5 分钟）

### 开场白

大家好！欢迎来到课程 A 的第一周。我是你们的老师 [姓名]。

在开始之前，我想问大家一个问题：**有多少人曾经想过做一个自己的小程序、小游戏或者小工具，但因为不会编程而放弃了？**

（举手互动，观察学生反应）

很好，我看到很多同学举手了。这很正常。在 AI 出现之前，编程确实是一个门槛很高的技能。但今天，我要告诉你们一个好消息：**这个门槛已经大大降低了。**

今天这节课，我们不讲语法、不配环境、不记命令。我们要做的是：**用对话的方式让 AI 帮你写代码，直接在网页上就能跑起来。**

### 课程目标

今天结束后，你们每个人都会：
1. 完成一个可以玩的贪吃蛇游戏
2. 理解什么是「对话式编程」
3. 知道 AI 能做什么、不能做什么
4. 学会如何清晰地向 AI 表达需求

准备好了吗？让我们开始吧！

## Part 1：认识 AI 编程（20 分钟）

### 1.1 小林的故事（5 分钟）

**[展示 PPT：小林的照片/插画]**

让我先给大家介绍一个人——小林。她是一名新闻传播专业的大三学生，和在座的很多同学一样，不是计算机专业的。

小林脑子里总有一堆产品点子：
- 一个帮自己记账的小工具
- 一个记录读书笔记的网页
- 甚至一款简单的小游戏

但每次想到要写代码、要找程序员，她就直接劝退了。

**[互动提问]**  
大家有没有类似的经历？想做点什么，但不知道怎么开始？

（等待学生回应）

直到有一天，小林在朋友圈看到有人用 AI 做出了一个贪吃蛇游戏，**只用了不到一小时**。那一刻她意识到：也许编程这件事，不再是程序员的专属技能了。

### 1.2 传统编程的困境（5 分钟）

**[展示 PPT：传统编程学习路径]**

让我们看看传统的编程学习路径是什么样的：

1. 学习编程语言（Python、JavaScript 等）
2. 配置开发环境（安装各种软件）
3. 学习框架和工具（React、Vue 等）
4. 写代码、调试、修 Bug
5. 部署上线

**[停顿，让学生感受]**

光是第一步「学习编程语言」就能劝退大部分人。更不用说后面的配置环境、学习框架了。

这就是为什么很多人有想法，但最终都没有实现。**门槛太高了。**

### 1.3 AI 带来的新可能（10 分钟）

**[展示 PPT：AI 编程数据]**

但 AI 的出现，第一次给了普通人一个全新的可能。

让我给大家看一组数据，来自 GitHub Copilot（全球最大的 AI 编程工具）：

- 超过 **1500 万开发者** 正在使用 AI 辅助编程
- 平均 **46% 的代码** 都是 AI 生成的
- 在 Java 项目中，这个比例能达到 **61%**
- 开发者完成任务的速度提升了 **55%**
- 原本需要 9.6 天的任务，现在只要 **2.4 天**

**[停顿，让数据沉淀]**

更重要的是采用率：在获得访问权限的当天，就有 **81%** 的开发者第一时间安装并使用；其中 **96%** 的人在当天就开始采纳 AI 提供的代码建议。

**[互动提问]**  
大家想想，这意味着什么？

（等待学生回应，引导到下一个观点）

对，这意味着：**如果专业程序员都在大量依赖 AI 写代码，那我们这些不会编程的人，为什么不能直接跟 AI 对话来实现自己的想法呢？**

**[展示 PPT：核心转变]**

这就是这门课要教你们的核心技能：
> 你不需要会写代码，只需要学会对 AI 说清楚你想要什么。

## Part 2：60 秒体验（25 分钟）

### 2.1 工具准备（5 分钟）

好，理论讲完了。现在让我们来一次「震撼体验」。

**[展示 PPT：z.ai 界面]**

请大家打开浏览器，访问 [z.ai](https://chat.z.ai/)。

**[等待学生打开网页，巡视确认]**

z.ai 是由智谱 AI 开发的 AI 平台。今天我们要用的是它的「全栈开发」功能——可以直接在网页上生成可运行的代码，无需安装任何软件。

**[演示操作]**  
看到这个界面了吗？左边是输入框，右边会显示生成的代码和预览。

### 2.2 生成第一个游戏（10 分钟）

现在，请大家跟着我一起做。

**[展示 PPT：提示词]**

在输入框中，输入这样一句话：

```
帮我做一个贪吃蛇游戏：
1. 用方向键控制蛇的移动
2. 吃到食物后蛇会变长，分数增加
3. 撞到墙壁或自己的身体就游戏结束
4. 要有开始和重新开始按钮
5. 界面要简洁好看
```

**[停顿，确保学生都输入完成]**

然后点击「全栈开发」按钮。

**[等待 30 秒]**

大家看到了吗？AI 正在生成代码。右侧的预览窗口已经显示出游戏界面了。

**[互动]**  
有同学已经可以玩了吗？试试用方向键控制蛇移动。

（巡视，帮助遇到问题的学生）

### 2.3 震撼时刻（5 分钟）

**[展示 PPT：小林的感受]**

小林第一次体验这个的时候，她说：
> "我只是说了我想要什么，AI 就帮我做出来了。这种感觉太神奇了！"

**[互动提问]**  
大家现在的感受是什么？

（让几个学生分享）

这就是「对话式编程」的魅力。你不需要知道 `function`、`for loop`、`if else` 是什么。你只需要用自然语言说清楚你想要什么。

### 2.4 对比传统编程（5 分钟）

**[展示 PPT：代码对比]**

让我给大家看看，如果用传统方式写这个贪吃蛇，需要多少代码：

```javascript
function moveSnake() {
  // 你需要写 50 行代码
  // 处理方向、碰撞检测、食物生成...
}
```

而用 AI 编程，你只需要说：
```
"让蛇每 100 毫秒移动一次"
```

**[停顿]**

核心区别是什么？**你负责「想」，AI 负责「做」。**

## Part 3：AI 原生实战（30 分钟）

### 3.1 什么是「AI 原生」（5 分钟）

**[展示 PPT：AI 原生定义]**

现在大家已经做出了一个基础的贪吃蛇。但我们可以让它变得更有趣。

什么是「AI 原生应用」？

- **传统应用**：功能固定，逻辑写死
- **AI 原生应用**：核心能力由 AI 提供，能理解、生成、创造

今天我们要做的是：让贪吃蛇不只是吃食物，还能：
1. 吃单词
2. 根据单词写诗
3. 根据诗歌画画

### 3.2 第二步：让蛇吃单词（8 分钟）

**[展示 PPT：提示词]**

请大家在 z.ai 的输入框中继续输入：

```
把食物改成随机的英文单词，
蛇吃到单词后，单词会显示在屏幕上方
```

**[等待学生操作]**

大家看到了吗？AI 修改了代码，现在蛇吃的不是红点，而是英文单词了。

**[展示 PPT：代码对比]**

让我给大家看看 AI 做了什么改动：

**之前**：
```javascript
food = { x: randomX, y: randomY }
```

**之后**：
```javascript
const words = ['apple', 'banana', 'cherry', ...]
food = { 
  x: randomX, 
  y: randomY, 
  word: words[Math.floor(Math.random() * words.length)]
}
```

AI 自动添加了单词库，并修改了食物的数据结构。

### 3.3 第三步：根据单词写诗（8 分钟）

**[展示 PPT：提示词]**

继续输入：

```
当蛇吃到 5 个单词后，
调用 AI API 根据这 5 个单词生成一首诗，
显示在游戏界面上
```

**[等待学生操作]**

这就是 AI 原生的魅力：
- 游戏逻辑由代码控制
- 创意内容由 AI 生成
- 两者完美结合

**[互动]**  
有同学已经看到诗歌了吗？分享一下你的 AI 写的诗。

（让 1-2 个学生分享）

### 3.4 调试技巧（9 分钟）

**[展示 PPT：好需求 vs 坏需求]**

在实际操作中，你们可能会遇到问题。比如 AI 生成的代码有 bug，或者效果不符合预期。

这时候，如何向 AI 描述问题就很重要了。

**坏例子**：
```
"有 bug，修一下"
```

**好例子**：
```
"当蛇吃到第 5 个单词时，
诗歌没有生成，
控制台显示 'API key not found' 错误，
请帮我检查 API 配置"
```

**[展示 PPT：对比表格]**

| 坏需求 | 好需求 |
|--------|--------|
| "有 bug" | "点击按钮后没反应，控制台报错 XXX" |
| "界面不好看" | "按钮太小，希望改成 48px 高度，圆角 8px" |
| "加个功能" | "希望添加暂停功能，按空格键暂停/继续游戏" |

**核心原则**：具体、可观察、可验证

## Part 4：能力边界（15 分钟）

### 4.1 AI 擅长做什么（5 分钟）

**[展示 PPT：AI 擅长的项目类型]**

现在大家已经体验了 AI 编程的魅力。但我们也要理性地认识 AI 的能力边界。

AI 擅长做什么？

✅ **小而完整的应用**（贪吃蛇、计算器、记账工具）
✅ **快速原型**（验证想法、展示 Demo）
✅ **重复性工作**（生成表单、CRUD 页面）
✅ **创意内容**（文案、图片、音乐）

**判断标准**：
> 5 分钟能说清楚的，AI 能做

### 4.2 AI 不擅长做什么（5 分钟）

**[展示 PPT：AI 不擅长的项目类型]**

AI 不擅长做什么？

❌ **大型系统**（电商平台、社交网络）
❌ **高安全性**（支付系统、医疗系统）
❌ **性能优化**（高并发、低延迟）
❌ **复杂业务逻辑**（多角色权限、复杂工作流）

**原因**：
- 上下文有限（记不住太多信息）
- 缺少全局视角（看不到整个系统）
- 无法保证正确性（可能产生幻觉）

### 4.3 三个层次（5 分钟）

**[展示 PPT：三个层次]**

从「能写」到「能用」有三个层次：

**Level 1：能跑起来**
- AI 生成的代码可以运行
- 基本功能正常

**Level 2：能用起来**
- 有错误处理
- 有 Loading 状态
- 有数据持久化

**Level 3：能上线**
- 有安全防护
- 有性能优化
- 有监控告警

**本周目标**：Level 1

后面的课程会教大家如何达到 Level 2 和 Level 3。
