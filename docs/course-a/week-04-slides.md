# Part 2

## 理解真需求

* * *

# 真需求 vs 假需求

**真需求的三个标准**：

1.  用户愿意为之付费
2.  用户愿意为之改变行为
3.  不解决会有很大损失

类型

特征

用户反应

**真需求**

不解决会很痛苦

「我愿意付钱」

**假需求**

有也挺好，没有也行

「挺有意思，但我不着急」

* * *

# 需求的三层

**痛点（Pain Point）—— 恐惧驱动**

-   不解决会很难受，甚至威胁生存
-   例子：糖尿病患者不知道吃多少碳水会血糖飙升

**爽点（Delight Point）—— 即时满足**

-   立即被满足，产生愉悦感
-   例子：外卖 30 分钟送达

**痒点（Itch Point）—— 虚拟自我**

-   想要变得更好，但不是必须的
-   例子：记录每天喝了多少水

* * *

# 优先级排序

```
痛点 > 爽点 > 痒点
```

**小明的健身 APP 解决的是痒点**

-   普通人想健身，但不健身也不会怎么样
-   Keep 已经够用了，为什么要换？
-   所以用户不愿意付费

* * *

# 案例一：美菜网

**表面**：帮餐馆买菜

**深层痛点**：

-   小餐馆老板每天凌晨 4 点起床去批发市场
-   很辛苦，经常被坑
-   美菜网让老板能睡个好觉

**关键洞察**：

> 省下的时间和体力，比省下的菜钱更有价值 痛点越痛，付费意愿越强

* * *

# 案例二：小红书

**表面**：分享海外购物心得

**深层痛点**：

-   面对海量商品，不知道什么值得买
-   需要信任的人帮自己筛选
-   节省时间，避免踩坑

**解决的是**：

-   选择困难
-   信任缺失

* * *

# 关键洞察

**用户买单的从来不是「功能」****而是「解决恐惧」和「消除焦虑」**

-   美菜网解决的是凌晨采购艰辛的恐惧
-   小红书解决的是买错东西的恐惧

**恐惧驱动付费，焦虑驱动行动**

* * *

# 验证真需求的快速方法

**找 10 个目标用户聊天**

但不要问「你会用我的产品吗？」

**要问**：

-   "你现在怎么解决这个问题？"（了解真实行为）
-   "最近一周，这个问题让你困扰了几次？"（了解频率）
-   "为了解决它，你花了多少钱/时间？"（了解付费意愿）
-   "如果有个解决方案，但需要改变习惯，你愿意吗？"（了解改变成本）

* * *

# 最好的验证方法

**让用户预付定金**

-   说愿意付费的人很多
-   真正掏钱的人才是你的目标用户

**验证指标**：

-   愿意付定金的用户比例 > 10%：需求真实，值得投入
-   低于 5%：需求不成立

# 为什么选择产后妈妈？

**四个原因**：

1.  **天然理解这个群体** — 室友就是产后妈妈，能直接观察痛点
2.  **痛点很痛** — 产后恢复的焦虑是真实的，不是「有也挺好」的痒点
3.  **付费意愿强** — 妈妈们为了恢复身材，愿意花钱
4.  **竞争相对不激烈** — 市面上没有专门针对产后妈妈的产品

* * *

# 产品经理的切分逻辑

**为什么切分人群这么重要？**

1.  **通用工具很难赢** — 大平台已经占据了「通用」市场
2.  **细分人群的需求更痛** — 产后妈妈对健身的需求是刚需
3.  **更容易建立口碑** — 服务好一个小群体，比讨好所有人更容易
4.  **付费意愿更强** — 细分人群的痛点更具体

* * *

# 实战：用 Claude Code 做人群分析

**对话示例**：

```
我想做一个健身相关的产品，但不知道该服务哪个人群。
请帮我分析：

1. 列出 5 个可能的细分人群
2. 分析每个人群的痛点强度、付费意愿、市场规模
3. 推荐最值得切入的人群
```

**Claude Code 会帮你系统地分析每个人群**

# Part 4

## 纵向深挖场景

* * *

# 观察用户的一天

**早上 6 点**

-   宝宝刚睡着，有 30 分钟空闲
-   想运动，但怕吵醒宝宝，也不知道做什么动作安全
-   **情绪：恐惧**（怕做错动作伤害身体）

**上午 10 点**

-   抱着宝宝哄睡，腰很酸
-   想做修复运动，但手没空
-   **情绪：焦虑**（身体不舒服但无法缓解）

* * *

# 观察用户的一天（续）

**下午 3 点**

-   宝宝睡觉，想运动
-   但身体很累，不知道还能不能做
-   **情绪：无助**（不知道自己的身体状态）

**晚上 8 点**

-   终于有空了，但很焦虑
-   看着镜子里的自己，觉得人生完蛋了
-   翻着以前的照片偷偷哭
-   **情绪：抑郁**（对身材的极度不满）

* * *

# 关键发现

**小雨的痛点不是「没有健身课程」**

**而是「产后恢复的恐惧和焦虑」**

-   **恐惧** — 担心身体恢复不好，留下后遗症
-   **焦虑** — 看着镜子里的自己，觉得人生完蛋了
-   **无助** — 不知道从何开始，也没人指导
-   **孤独** — 别人随便生，我却要恢复这么久

* * *

# 产品经理的场景思维

**痛点 = 场景中的情绪 + 付费意愿**

很多人以为痛点就是功能需求，其实不是。

**好的产品设计**：

-   要解决的是情绪，而不只是功能
-   情绪背后，是用户付费的动力

* * *

# 价值重构

**从「健身 APP」到「产后妈妈恢复助手」**

不只是健身工具 而是产后妈妈的「专属康复教练 + 心理支持者」

* * *

# 核心功能设计

**1\. 碎片化训练**

-   每次只需 10-15 分钟
-   宝宝睡觉时也能练
-   提供「抱着宝宝也能做」的动作

**2\. 产后专属课程**

-   按产后阶段分级（0-3 个月、3-6 个月、6 个月以上）
-   针对腹直肌分离、盆底肌修复的专项训练
-   每个动作都有「产后注意事项」提示

* * *

# 核心功能设计（续）

**3\. AI 动作纠正**

-   手机摄像头识别动作
-   实时提示「膝盖太弯了」、「背部要挺直」
-   避免错误动作伤害身体

**4\. 心理支持社区**

-   只有产后妈妈的私密社区
-   分享恢复进度，互相鼓励
-   专业心理咨询师入驻

* * *

# 商业模式

-   **基础课程**：免费
-   **高级课程**：99 元/月（含 AI 动作纠正、专属方案）
-   **一对一私教**：299 元/月（线上指导）
-   **社群会员**：199 元/年（含心理支持、专家答疑）

* * *

# 从「功能」到「解决方案」的进化

**原始想法：健身 APP**

-   目标用户：所有想健身的人（大而泛）
-   解决痛点：记录训练数据（痒点）
-   核心功能：课程、打卡、社区
-   付费意愿：低（免费替代多）

**重构后：产后妈妈恢复助手**

-   目标用户：产后妈妈（精准）
-   解决痛点：产后恢复焦虑（痛点）
-   核心功能：碎片化训练 + AI 纠正 + 心理支持
-   付费意愿：高（刚需 + 情绪价值）

# Part 5

## 快速验证

* * *

# MVP（最小可行产品）规划

**不要一上来就做完整的 APP**

用最小的成本验证核心假设

* * *

# 第一阶段：验证需求（1-2 个月）

**目标**：验证产后妈妈是否愿意为「专属恢复方案」付费

**最小化实现**：

1.  不做 APP，先做微信小程序（开发成本低）
2.  只提供核心功能（产后专属课程视频 + 打卡社区）
3.  人工动作指导（用户上传视频，教练回复）
4.  内容制作：找 2-3 位产后康复教练合作，用分成模式

**前期成本：< 1000 元**

* * *

# 验证指标

**目标**：

-   100 个用户
-   付费转化率 > 10%

**如果达到**：说明需求真实，继续投入 **如果达不到**：及时调整方向

* * *

# 推广策略

**1\. 小红书**（最推荐）

-   搜索「产后恢复」、「腹直肌分离」
-   找相关博主，私信合作
-   用「免费体验 1 个月」换取推广
-   成本：几乎为 0

**2\. 妈妈群**

-   搜索微信群、QQ 群
-   以「产后恢复经验分享」的名义进群
-   分享干货内容，不要直接广告

* * *

# 推广策略（续）

**3\. 医院妇产科合作**

-   提供免费的产后恢复指导
-   在医院发放宣传单
-   成本：印刷费几百元

**4\. 母婴店合作**

-   放置宣传物料
-   购买母婴产品赠送体验卡

# 更多案例

* * *

# 案例一：从「记账 APP」到「留学资金管家」

**普通想法**：自动记账 APP

**问题**：随手记、挖财、支付宝账单已经很成熟

**横向切分**：留学生家长 — 想知道孩子在外国花了多少钱

**纵向深挖**：痛点是「失控感」— 孩子花多少钱不知道

**重构后**：「留学资金管家」— 让家长对孩子的海外消费「心中有数」

* * *

# 案例二：从「番茄钟工具」到「远程工作证明」

**普通想法**：番茄钟 APP，帮助用户专注工作

**问题**：Forest、番茄 ToDo 已经很成熟

**横向切分**：远程工作者 — 需要向老板证明「我真的在工作」

**纵向深挖**：痛点是「信任危机」— 老板看不到我，怎么证明？

**重构后**：「远程工作证明」— 帮远程工作者建立与雇主的信任

* * *

# 方法论总结

**从普通 idea 到好点子的三步法**：

1.  **横向切分** — 找到一个特定人群，他们的需求更痛、更具体
2.  **纵向深挖** — 理解完整场景，找到情绪触点
3.  **价值重构** — 从「工具」升级为「解决方案」
