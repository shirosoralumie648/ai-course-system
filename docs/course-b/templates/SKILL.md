### 输出示例

```markdown
## 概览
- 审查文件数：3
- 发现问题数：5
- 严重程度：中

## 问题列表

### 问题 1：SQL 注入风险
- **文件**：src/database/query.js
- **行号**：25
- **严重程度**：高
- **描述**：直接拼接 SQL 字符串，存在 SQL 注入风险
- **建议**：使用参数化查询或 ORM

### 问题 2：未处理的异常
- **文件**：src/api/users.js
- **行号**：42
- **严重程度**：中
- **描述**：异步操作未处理异常，可能导致程序崩溃
- **建议**：添加 try-catch 或 .catch() 处理

## 总结
代码整体质量良好，但存在安全隐患和异常处理不足的问题。建议优先修复 SQL 注入问题。
```

```markdown
# 代码审查报告

## 概览
- 审查文件数：1
- 发现问题数：2
- 严重程度：高

## 问题列表

### 问题 1：潜在的 XSS 漏洞
- **文件**：src/utils/helper.js
- **行号**：15
- **严重程度**：高
- **描述**：直接将用户输入插入 HTML，存在 XSS 风险
- **建议**：使用 DOMPurify 或类似库进行输入清理

### 问题 2：性能问题
- **文件**：src/utils/helper.js
- **行号**：28
- **严重程度**：中
- **描述**：在循环中频繁操作 DOM，影响性能
- **建议**：使用 DocumentFragment 或虚拟 DOM

## 总结
代码存在安全隐患，建议立即修复 XSS 漏洞。性能问题可在后续优化。
```
