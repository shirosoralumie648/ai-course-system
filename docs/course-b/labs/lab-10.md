## 实验目标

1. 理解企业知识库不只是向量检索，还需要知识治理。
2. 能把知识拆成不同知识域，并说明路由逻辑。
3. 能设计 RAG 评测表，记录准确性、引用、拒答和稳定性。
4. 能用改进前后对比证明一次优化是否有效。

## 实验任务

基于 Lab 09 的最小 RAG，完成一次企业级 RAG 改造设计和最小验证。你可以在 Dify、LlamaIndex、LangGraph、Haystack、本地脚本或表格模拟中完成，重点是流程和证据。

必须提交：

- 企业知识库架构图或流程图。
- 知识域拆分表。
- 版本与权威来源规则。
- 至少 12 条问题的 RAG eval sheet。
- 一次改进前后对比记录。

## 操作步骤

### 第一步：复盘 Lab 09 失败样本

从 Lab 09 的测试日志中选择至少 3 条样本：

- 1 条回答正确的样本。
- 1 条检索错误的样本。
- 1 条应该拒答但没有拒答的样本。

记录每条样本的问题、命中文档、回答、错误原因和预期行为。

### 第二步：设计知识域拆分

把资料按业务含义拆分为 2-4 个知识域，例如：

| 知识域 | 包含资料 | 适合回答的问题 | 不应该回答的问题 |
|---|---|---|---|
| 产品功能 | 功能说明、版本说明 | 功能支持、限制、差异 | 订单状态、个人数据 |
| 流程政策 | 退款、开票、售后流程 | 规则和办理步骤 | 实时审批进度 |
| 技术文档 | API、部署、错误码 | 技术接入和排障 | 价格承诺 |

如果当前资料较少，也要写出未来扩展时如何拆分。

### 第三步：制定治理规则

至少写清楚以下规则：

1. 版本规则：新旧文档冲突时以哪个版本为准。
2. 权威规则：产品手册、销售话术、历史 FAQ 的优先级。
3. 边界规则：哪些问题必须拒答或要求补充信息。
4. 引用规则：回答必须附带文档标题、段落编号或链接。
5. 安全规则：不得输出隐私、密钥、内部账号或未公开承诺。

### 第四步：制作 eval sheet

创建 `rag-eval-sheet.md` 或表格文件，至少包含 12 条评测样本：

| 编号 | 问题 | 知识域 | 标准答案要点 | 应命中来源 | 实际回答 | 引用是否正确 | 评分 | 备注 |
|---|---|---|---|---|---|---|---:|---|
| 1 |  |  |  |  |  |  |  |  |

评分建议：

- 2 分：答案正确且引用正确。
- 1 分：答案部分正确或引用不完整。
- 0 分：答案错误、无依据编造或应拒答未拒答。

### 第五步：执行一次改进

选择一个明确改进方向，不要同时改太多：

- 重新组织文档目录。
- 调整切块大小或重叠。
- 增加版本字段或文档标题。
- 修改提示词，要求证据不足时拒答。
- 增加问题路由或知识域选择。
- 使用 rerank、关键词过滤或人工标注表。

如果无法使用平台或框架，可以用本地脚本或人工表格模拟改进，但必须保留改动说明和对比证据。

### 第六步：对比评测结果

改进前后都跑同一份 eval sheet，计算：

- 总分变化。
- 引用正确率变化。
- 拒答正确率变化。
- 仍未解决的失败样本。

结论必须由数据支持，不能只写“效果更好了”。

## 提交要求

1. `knowledge-domain-map.md`：知识域拆分表。
2. `governance-rules.md`：版本、权威、边界、引用和安全规则。
3. `rag-eval-sheet.md` 或电子表格导出。
4. 改进前后截图、日志或录屏。
5. 企业知识库架构图，可用 Mermaid、手绘照片或绘图工具。
6. 平台、框架或账号不可用时的替代流程说明。

## 验收标准

- 知识域拆分符合项目业务，不是随意分类。
- 治理规则能处理版本冲突、权威来源和资料不足。
- eval sheet 至少 12 条，包含成功、失败和边界问题。
- 改进结论有前后数据支撑。
- 有截图、日志、表格或录屏作为具体证据。
- 替代方案能说明高级 RAG 思路，而不是只写概念。

## 常见问题

**一定要用 LangGraph 或 LlamaIndex 吗？**

不强制。本实验重点是企业知识库设计和评测。可以用平台、代码或表格完成，但要体现知识域、治理规则和评测证据。

**只有一份文档怎么拆知识域？**

可以按章节或问题类型拆分，例如“产品功能、使用流程、限制说明”。同时说明资料不足对结果的影响。

**改进后分数没有提升怎么办？**

可以接受。只要你说明改进假设、执行过程和失败原因，就是有效实验。

**标准答案要写多详细？**

写关键要点即可，但必须能判断模型回答是否覆盖了必要信息。
