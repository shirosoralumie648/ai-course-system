## 实验目标

1. 判断期末产品是否适合优先做 PWA。
2. 掌握 manifest、service worker、缓存策略和安装体验的基本关系。
3. 能把 Web 产品的一条核心路径做成可安装、可离线打开的原型。
4. 能说明 PWA 与小程序、移动端 App 的取舍。

## 实验任务

选择期末产品中一条核心路径，例如“登录后查看课程”“创建一条笔记”“查询知识库答案”“查看订单状态”。在不重写全部产品的前提下，完成 PWA 最小原型。

必须提交：

- 平台决策矩阵。
- PWA manifest 配置截图或代码片段。
- Service worker 或 PWA 插件配置说明。
- 安装成功截图。
- 离线访问截图或浏览器日志。
- 限制说明和下一步计划。

## 操作步骤

### 第一步：选择核心路径

写清楚本次 PWA 只迁移哪一条路径：

| 项目 | 内容 |
|---|---|
| 目标用户 |  |
| 核心路径 |  |
| 必须可用页面 |  |
| 可以暂缓能力 |  |
| 需要离线的内容 |  |

不要把“所有功能都 PWA 化”作为本实验目标。

### 第二步：填写平台决策矩阵

比较 Web、PWA、小程序、移动端 App：

| 维度 | Web | PWA | 小程序 | 移动端 App |
|---|---|---|---|---|
| 用户入口 |  |  |  |  |
| 安装成本 |  |  |  |  |
| 离线能力 |  |  |  |  |
| 推送能力 |  |  |  |  |
| 支付或登录限制 |  |  |  |  |
| 维护成本 |  |  |  |  |
| 本项目适配度 |  |  |  |  |

结论必须和用户场景相关，不能只写“PWA 更方便”。

### 第三步：添加 manifest

为项目添加或检查 `manifest.webmanifest`：

```json
{
  "name": "项目名称",
  "short_name": "短名称",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#111827",
  "icons": []
}
```

如果项目使用 Vite，可以手动添加，也可以使用 PWA 插件。记录你选择的方式和原因。

### 第四步：实现最小离线能力

选择一种可控缓存策略：

- 只缓存首页和静态资源。
- 缓存核心页面外壳，动态数据上线后再请求。
- 为离线状态显示“当前无网络，请稍后同步”。

不要缓存敏感用户数据、支付状态、权限数据或 AI 调用结果，除非你能说明安全策略。

### 第五步：验证安装和离线访问

至少完成以下验证：

1. 本地或部署地址能打开。
2. 浏览器 Application 面板能看到 manifest。
3. 浏览器能注册 service worker。
4. 可以安装到桌面或手机主屏。
5. 断网后仍能打开首页或指定核心页面。

保存截图或录屏。无法真机测试时，可使用 Chrome DevTools 的离线模式截图。

### 第六步：记录限制与下一步计划

写清楚 PWA 当前限制：

- 哪些平台安装体验不好。
- 哪些功能离线不可用。
- 登录、支付、推送、文件上传是否有限制。
- 后续是否仍需要小程序或移动端 App。

## 提交要求

1. 平台决策矩阵。
2. PWA 运行链接或本地运行命令。
3. manifest 配置截图或代码片段。
4. service worker 注册截图或日志。
5. 安装成功截图。
6. 离线访问截图或录屏。
7. 安全与限制说明。
8. 如果浏览器或平台不支持安装，提交失败截图和替代验证方式。

## 验收标准

- 只选择一条核心路径，目标清楚且可完成。
- PWA manifest 基本字段完整。
- 有 service worker 或等价 PWA 插件配置。
- 有安装证据和离线访问证据。
- 决策矩阵能解释为什么本项目适合或不适合 PWA。
- 没有把敏感数据随意缓存到本地。

## 常见问题

**PWA 必须部署到 HTTPS 吗？**

正式环境通常需要 HTTPS。本地开发可使用 `localhost` 验证。若无法部署，需要提交本地验证截图和限制说明。

**图标没有准备好怎么办？**

可以先使用简单占位图标，但要记录为待替换项。不要因为图标问题跳过 manifest。

**离线时 API 数据加载失败算不算失败？**

不一定。核心是页面外壳能打开，并对动态数据失败有合理提示。敏感或实时数据不应盲目缓存。

**浏览器没有出现安装按钮怎么办？**

检查 manifest、service worker、HTTPS、图标和控制台错误。提交排查日志也算证据。
