# Claude Code 安装指南

## 安装步骤

Claude Code 的安装命令以官方文档为准。请访问 Anthropic 官方网站获取最新安装指南。

## 安装后验证

安装完成后，运行以下命令验证：

```bash
claude --version
```

如果命令能正常输出版本号，说明安装成功。

## 验证能力清单

安装成功后，你需要验证以下能力：

1. 能启动 Claude Code
2. 能让它读取当前目录的文件
3. 能让它分析代码
4. 能让它提出修改计划
5. 能审查它的 diff
6. 能在它修改后运行测试

## 常见问题

| 问题 | 可能原因 | 解决方案 |
|---|---|---|
| 登录失败 | 账号或网络问题 | 检查网络连接，确认账号状态 |
| 模型不可用 | 地区限制或权限问题 | 联系教师获取备用方案 |
| 路径有中文 | 特殊字符导致异常 | 使用纯英文路径 |
| 权限不足 | 沙箱限制 | 检查权限配置 |

## 工具不可用怎么办？

如果 Claude Code 无法安装或使用：

1. 记录错误截图或日志
2. 先完成实验中不依赖工具的部分（文档分析、规则设计）
3. 使用教师的演示环境观察完整流程
4. 不要伪造工具运行结果
