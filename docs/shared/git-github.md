# Git 与 GitHub 基础

## 你需要掌握的操作

| 操作 | 命令 | 用途 |
|---|---|---|
| 克隆仓库 | `git clone <url>` | 下载项目到本地 |
| 查看状态 | `git status` | 查看哪些文件有改动 |
| 查看 diff | `git diff` | 查看具体改了什么 |
| 提交 | `git add . && git commit -m "描述"` | 保存改动 |
| 推送 | `git push` | 上传到远程仓库 |

## 实验中的 Git 使用

每个实验都需要你保留完整的 Git 历史：

1. 实验开始前：确认在正确的分支上
2. Agent 修改代码后：用 `git diff` 查看所有改动
3. 验证通过后：提交并推送

## 提交作业

1. 在 GitHub 上创建仓库
2. 将实验记录和代码推送到仓库
3. 提交仓库链接

## 安全提醒

- **永远不要**提交 API Key、Token、密码
- **永远不要**提交 `.env` 文件
- 使用 `.gitignore` 排除敏感文件
