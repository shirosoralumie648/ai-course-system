# Codex CLI 安装指南

## 安装步骤

Codex CLI 的安装命令以官方文档为准。请访问 OpenAI 官方网站获取最新安装指南。

## 安装后验证

```bash
codex --version
```

## 验证能力清单

1. 能启动 Codex CLI
2. 能让它读取当前目录
3. 能理解 sandbox 和 approval 机制
4. 能审查它的修改计划
5. 能审批或拒绝高风险操作

## 常见问题

| 问题 | 可能原因 | 解决方案 |
|---|---|---|
| 认证失败 | API Key 问题 | 检查 Key 是否有效 |
| 模型不可用 | 地区或权限限制 | 联系教师获取备用方案 |
| 终端不兼容 | Shell 环境问题 | 使用推荐的终端 |
| 沙箱限制 | 权限配置 | 检查权限设置 |

## 工具不可用怎么办？

与 Claude Code 相同：记录错误、先做非工具部分、观察教师演示、不要伪造结果。
