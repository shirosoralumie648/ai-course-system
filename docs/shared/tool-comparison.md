# Claude Code vs Codex 对比

## 核心差异

| 维度 | Claude Code | Codex |
|---|---|---|
| 交互方式 | 对话式，逐步确认 | 任务式，一次提交 |
| 执行模式 | 直接修改文件 | sandbox 隔离执行 |
| 审批机制 | 每步可确认 | 集中审批 |
| 适用场景 | 复杂任务，需要多次交互 | 明确任务，一次性完成 |

## 选择建议

- **需要多次交互、逐步确认**：用 Claude Code
- **任务明确、一次性完成**：用 Codex
- **不确定**：先用 Claude Code，因为它更灵活

## 课程中的对比

在课程 A 的 Claude Code 工作流实验和课程 B 的 CLI/Git/AI 工程流实验中，你会记录不同工具处理同类任务的差异。对比时关注：

1. 任务描述方式的差异
2. 计划和执行的差异
3. 审批和权限的差异
4. 最终结果的差异

<InfoCard icon="💡" variant="tip">
对比不是为了分出"哪个更好"，而是理解"不同工具适合不同场景"。用证据说话，不要用感觉。
</InfoCard>
