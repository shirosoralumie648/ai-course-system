## 工具不可用怎么办？

如果 Claude Code 或 Codex 无法安装或使用：

1. **记录错误**：截图或保存错误日志
2. **先做非工具部分**：文档分析、规则设计等不依赖工具的任务
3. **观察教师演示**：使用教师的演示环境观察完整流程
4. **不要伪造结果**：如实记录环境问题，这会被视为有价值的 Alpha 反馈

<InfoCard icon="💡" variant="tip">
安装问题不是你的错。不同机器环境、网络条件、账号状态都可能影响工具可用。如实记录问题本身就是一种工程能力。
</InfoCard>
