# 课程 C Reference 融入方案：从工具资料到专业工作流

> Course C 的 reference 不只是工具教程。业务、财务、法务、HR、投资、税务、产品、品牌和销售场景必须同时区分"怎么实现"和"专业判断依据从哪里来"。

## 两类来源

| 来源类型 | 解决的问题 | 示例 | 不能替代什么 |
|---|---|---|---|
| 实现来源 | 工具怎么接入、文件怎么组织、Prompt/Skill/API/MCP 怎么写、如何验证运行结果 | Claude Code / Codex 文档、API/MCP 文档、SaaS 帮助中心、参考项目 README、代码示例 | 不能证明财务、法律、投资、HR、税务或市场判断本身正确 |
| 权威领域来源 | 专业方法、监管规则、业务标准、审查依据和风险边界 | 经典教材、专业书籍、同行评审论文、官方法律法规、监管指引、会计/审计/隐私/安全标准、行业协会材料 | 不能直接告诉你某个工具按钮在哪里或代码怎么写 |

后续专业页面必须把这两类来源分开写。实现来源告诉学生如何完成 AI 工作流，权威领域来源告诉学生这个业务判断为什么站得住。

## 权威领域来源类别

| 类别 | 适用场景 | 使用方式 |
|---|---|---|
| 经典书籍或教材 | 产品设计、市场调研、品牌、销售、管理、组织行为、财务管理 | 抽取框架、术语和判断维度，改写成课堂模板 |
| 同行评审论文或综述 | 数据分析、消费者研究、组织管理、决策科学、AI 辅助工作影响 | 用于说明方法有效性、局限和适用条件 |
| 官方法律法规 | 税务、合同、劳动、人力、数据合规、证券投资、公司治理 | 用于定义 AI 不能越过的红线和人类审批点 |
| 官方标准和监管指引 | 会计、审计、隐私、安全、金融合规、企业系统治理 | 用于设计审查清单、记录留存和风险控制 |
| 行业组织材料 | 销售、市场、HR、项目管理、信息安全、财务内控 | 用于把行业实践改写成 SOP 或评价表 |

Phase 1 只建立来源规则和分类。每周详细书单、论文、法规和标准清单会在后续周页面中补齐。

## Course C 的 reference 使用流程

| 步骤 | 学生要做什么 | 交付证据 |
|---|---|---|
| 1. 定义业务任务 | 写清楚岗位、输入、输出、审批人和风险等级 | 任务卡、角色边界 |
| 2. 选择实现来源 | 找到工具文档、参考项目或 SaaS 指南，说明怎样完成工作流 | 工具路径、Prompt/Skill、操作记录 |
| 3. 选择权威领域来源 | 找到书籍、论文、法规、标准或监管/行业材料，说明专业判断依据 | 来源表、引用范围、适用边界 |
| 4. 运行 AI 工作流 | 让 AI 整理资料、生成草稿、制作表格或提出检查项 | 输入、输出、人工修改 |
| 5. 做四门审查 | 数据门、来源门、人类门、审计门逐项检查 | 脱敏记录、来源记录、审批记录、审计日志 |
| 6. 更新助理包 | 把可复用做法沉淀成模板、SOP、Skill 或 checklist | 助理包文件更新 |

## 引用与使用模板

每个专业任务至少保留一条实现来源记录和一条权威领域来源记录。引用不要求长篇综述，但必须写清楚它支撑了什么、没有支撑什么。

```markdown
## 引用与使用记录

- 来源：
- 来源类型：实现来源 / 权威领域来源 / 公开资料 / 内部规则
- 阅读范围：
- 支撑了哪个判断：
- 适用边界：
- 不能推出什么结论：
- 进入 AI 工作流的证据：
```

详细周页面会继续补齐具体书籍、教材、论文、法规、标准、监管指引、公开披露材料和行业组织资料。Phase 3、Phase 4 和 Phase 5 的 Week 页面负责把这些来源落到具体任务，不在本页提前写完整书单。

## 写作格式

每个后续专业页面至少保留这个来源区块：

```markdown
## Reference 使用

### 实现来源

- 来源：
- 用来解决：
- 我如何简化到本周任务：
- 验证证据：

### 权威领域来源

- 来源：
- 适用范围：
- 支撑了哪个判断：
- 不能推出什么结论：
```

## 边界声明

- 工具文档和代码示例只说明实现路径，不是专业结论依据。
- AI 输出可以用于草拟、归纳、比较、检查和重组材料。
- 投资、法律、税务、财务、HR、合规和公司治理结论必须由负责人或专业人员确认。
- 公开页面不得依赖本地忽略的 `reference/repos/` 内容；引用时要写成读法和方法，而不是要求访问本地仓库。

详细课程成果见 [期末项目](/course-c/final-project)，评分证据见 [评分标准](/course-c/rubric)。
