## 业务情境

星河咖啡设备准备复盘三个月渠道扩张预算：设备采购、安装服务、售后维护、品牌活动和销售费用都有差异。财务管理助理要把 sample 财务数据整理成预算差异表和复核问题。

本周输出关注“解释材料”而不是“最终财务判断”：

| 工作 | AI 支持 | 不能直接推出 |
|---|---|---|
| 预算差异 | compare 预算与实际 | 不能直接批准预算调整 |
| 成本分类 | classify 费用类别 | 不能直接确定最终会计科目 |
| 成本动因 | analyze 可能原因 | 不能直接确认真实原因 |
| 报表说明 | draft 管理层说明 | 不能替代财务报表审阅 |
| 复核清单 | prepare checklists | 不能跳过财务负责人确认 |

## 角色边界

| 角色 | AI 可以支持 | AI 不能直接做 |
|---|---|---|
| 财务管理助理 | organize sample 数据、summarize 差异、generate questions | 做最终会计处理或审计结论 |
| 成本会计 | review 成本分类、compare 口径 | 让 AI 直接决定成本归集和分摊 |
| 预算负责人 | analyze 预算执行线索 | 直接批准预算追加或削减 |
| 财务负责人 | 确认报表说明、内控和审批 | 用 AI 草稿替代专业判断 |

必须由负责人或专业人员确认：成本科目、收入确认、费用归属、预算调整、财务报表说明、内控例外和审计沟通。

## 输入资料

- [sample-finance.csv](/course-c/examples/sample-finance.csv)。
- Week 07 KPI 字典和 Week 09 BP 资金用途草稿。
- fictional / sample 预算表、费用明细和项目负责人批注。
- 公司财务制度、预算制度或教师提供的 sample 内控规则。
- [合规检查清单](/course-c/templates/compliance-checklist)。

不要上传真实银行流水、工资明细、税号、发票原件、客户收款账号、供应商敏感合同或未披露财务报表。

## AI 工作流

### 第一步：数据口径说明

```text
请基于 sample-finance.csv 生成财务数据口径说明。
字段：数据列、业务含义、来源、是否 sample、负责人、可用于哪些分析、不能用于哪些结论。
```

### 第二步：预算差异分析

```text
请对以下 sample 预算与实际数据做差异分析。
要求：
1. 输出差异金额和差异率。
2. 只写可能原因和待确认问题。
3. 标注需要项目负责人或财务负责人确认的项。
4. 不写最终会计判断或预算审批结论。
```

### 第三步：成本分类复核

```text
请把费用明细初步分类为设备采购、安装服务、售后维护、销售费用、品牌推广、行政费用。
每条写：分类理由、来源字段、风险、需要财务确认的问题。
如果信息不足，请写“无法判断”。
```

### 第四步：财务复核问题

```text
请生成财务负责人复核问题清单。
分类：数据完整性、成本分类、预算差异、内控例外、报表说明、后续行动。
每个问题写需要查看的证据。
```

## 工具与应用整合

| 工具 | 用途 | 证据 |
|---|---|---|
| 表格工具 | 预算差异表和成本分类表 | 公式、字段和版本 |
| BI 或仪表盘工具 | 预算执行视图 | 截图或字段表 |
| 文档工具 | 财务说明和复核问题 | 修订记录 |
| AI 工具 | analyze 差异、classify 成本、prepare checklists | Prompt 和人工修改 |
| 审计日志 | 记录数据版本和审批 | [审计日志模板](/course-c/templates/audit-log) |

AI 输出只能进入复核包。任何预算调整、账务处理、报表披露和管理行动都要走公司审批。

## Reference 使用

### 实现来源

- 表格和 BI 工具文档：用于公式、透视表、图表和导出说明。
- [sample-finance.csv](/course-c/examples/sample-finance.csv)：作为本周 sample 数据。
- [ROI 报告模板](/course-c/templates/roi-report)：用于记录财务流程改进。
- [合规检查清单](/course-c/templates/compliance-checklist)：用于执行四门审查。

### 权威领域来源

- 管理会计、成本会计和财务管理教材可支持成本分类、预算差异和责任中心分析。
- COSO Internal Control 或企业内控资料可支持审批、职责分离和例外处理。
- IFRS、US GAAP、中国企业会计准则或本地适用会计准则用于正式会计处理；课堂练习不能替代注册会计师或财务负责人判断。
- 审计和数据质量资料可帮助记录证据链，但不能替代审计意见。

## 合规审查

| 门 | 检查问题 |
|---|---|
| 数据门 | 是否只使用 sample、虚构、公开或脱敏财务数据？ |
| 来源门 | 每个差异、分类和说明是否能追溯到字段、制度或权威来源？ |
| 人类门 | 成本分类、预算调整和报表说明是否由财务负责人确认？ |
| 审计门 | 是否保存数据版本、公式、Prompt、人工修改和审批记录？ |

AI 可以支持 draft、analyze、organize、compare、review、summarize、classify、generate questions、prepare checklists、record workflow evidence。AI 不能直接做最终会计处理、预算审批、审计意见、财务报表签发、付款或生产系统写入。

## 助理包更新

更新财务管理助理：

- 新增工作流：数据口径 -> 预算差异 -> 成本分类 -> 复核问题 -> 审批记录。
- 新增提示词：财务数据口径、预算差异、成本分类、内控复核。
- 新增模板：预算差异表、成本分类复核表、财务负责人问题清单。
- 新增审计规则：凡涉及最终会计、预算审批、报表披露和付款动作，必须转人工。

## 验收标准

- 预算差异表写清预算、实际、差异金额、差异率和可能原因。
- 成本分类表包含分类理由、来源字段、风险和财务确认问题。
- 财务复核问题覆盖数据完整性、成本分类、预算差异、内控和报表说明。
- 至少引用 1 个管理会计、成本会计、财务管理、内控或会计准则权威领域来源。
- 没有让 AI 直接做最终会计判断、预算审批或审计结论。
