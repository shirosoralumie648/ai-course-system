# 期末项目：岗位 AI 助理包与真实工作流改造

> **期末项目不是 prompt 集合。** 你要证明一个岗位可以用 AI 形成可复用、可审批、可审计的工作流，并且这个工作流让真实或 realistic 的业务流程变得更清楚、更快或更稳。

- 为一个岗位建立可复用 AI 助理包
- 改造一个真实或仿真的业务流程
- 用证据说明效率、质量、风险或一致性改进

</ChapterIntroduction>

## 项目目标

选择一个具体岗位或管理场景，完成两个成果：

1. **岗位 AI 助理包**：能被同岗位的人复用，包含角色边界、工作流、模板、提示词、工具、数据结构和合规材料。
2. **真实工作流改造报告**：选择一个当前流程，说明改造前、改造后、人工审批点、审计证据和改进效果。

## 可选岗位方向

| 岗位方向 | 可选流程 |
|---|---|
| 市场 / 品牌 | 行业研究、竞品分析、内容日历、活动素材审查 |
| 产品 / 设计 | 需求整理、定位说明、用户画像、原型提示词 |
| 销售 / BD | 目标客户分层、渠道开拓、客户跟进、销售漏斗复盘 |
| 数据 / 运营 | KPI 树、经营仪表盘、异常分析、月度经营报告 |
| 投资 / 战略 | 公开公司研究、估值假设、风险披露、投资备忘录草稿 |
| 财务 / 税务 | 预算分析、成本核算、资料清单、申报 SOP、报表解释 |
| 人力资源 | 招聘、培训、薪酬福利核算辅助、绩效流程、文化建设 |
| 法务 / 合规 | 合同初审、纠纷材料整理、政策草案、合规检查 |
| 行政 / 综合管理 | 会议安排、固定资产、资质维护、办公环境、制度落地 |

## 必交材料

| 材料 | 要求 |
|---|---|
| 岗位 AI 助理包 | 至少包含角色画像、3 个工作流、5 个任务提示词、3 个模板、工具清单和合规材料 |
| 工作流改造报告 | 包含 before-state、after-state、痛点、AI 支持方式、人工审批点、风险控制和改进证据 |
| 输入资料说明 | 说明使用了哪些样例资料、公开资料或脱敏资料 |
| Reference 使用说明 | 分开写实现来源和权威领域来源，说明各自支撑了什么 |
| 合规证据包 | 数据门、来源门、人类门、审计门四项记录 |
| 可复用资产清单 | 列出工作流、prompts、templates、SOP、字段表、审查清单和案例证据 |
| ROI / quality / risk 证明 | 至少提供一种可检查的时间、质量、错误减少、风险可见性或一致性证据 |
| 答辩材料 | 5-8 分钟展示，包含流程演示、关键证据和风险边界 |

## 工作流改造报告

报告至少回答这些问题：

| 问题 | 说明 |
|---|---|
| 原流程是什么 | 谁发起、谁处理、输入是什么、输出是什么、卡点在哪里 |
| AI 改造了什么 | AI 负责草拟、整理、分析、检查、转格式还是生成看板 |
| 人保留什么职责 | 哪些判断、发布、提交、审批、投资、合同、税务、招聘或处罚必须由人决定 |
| 如何验证 | 时间节省、错误减少、格式一致、审查更完整、风险更可见或沟通更顺畅 |
| 如何复用 | 其他同岗位同学是否能照着助理包执行 |

## 高风险场景要求

如果项目涉及投资、投行、财务、税务、HR、法律、行政治理或企业系统连接，必须写清楚：

- AI 只能支持草稿、分析、整理、检查和流程记录。
- AI 不直接做买卖建议、纳税申报、法律意见、录用/辞退、薪酬决定、合同签署或生产系统写入。
- 关键输出需要负责人、专业人员或管理者审批。
- 输入资料、AI 输出、人工修改和最终版本必须留痕。

## 答辩结构

1. 1 分钟：岗位、业务问题和原流程。
2. 2 分钟：岗位 AI 助理包结构和一个核心工作流演示。
3. 1 分钟：Reference 使用，区分实现来源和权威领域来源。
4. 1 分钟：合规证据包和人类审批点。
5. 1 分钟：改造效果，说明 ROI、时间、质量、风险或一致性证据。
6. 1 分钟：限制和下一步。

评分细则见 [评分标准](/course-c/rubric)。
