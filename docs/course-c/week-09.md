## 业务情境

星河咖啡设备计划进入 3 个新城市，需要准备一份内部融资评审 BP。材料包含市场机会、产品线、收入模型、销售计划、成本投入、风险因素和资金用途。

AI 的价值是把散乱信息整理成可审查的包：

| 材料 | AI 支持方式 | 高风险边界 |
|---|---|---|
| BP 目录 | organize 章节和证据 | 不生成虚假增长承诺 |
| 财务摘要 | compare sample 预算和实际口径 | 不做最终估值 |
| 尽调清单 | prepare checklists | 不认定资料已经充分 |
| 路演 Q&A | generate questions 和 draft 回答 | 不写招揽或承诺收益 |
| 版本审计 | record workflow evidence | 不替代负责人签批 |

## 角色边界

| 角色 | AI 可以支持 | AI 不能直接做 |
|---|---|---|
| 投行业务助理 | draft BP 大纲、organize 尽调资料、summarize 风险 | 决定最终融资条款 |
| 财务负责人 | review 财务表、compare 预算口径、generate questions | 确认最终估值或交易结构 |
| 法务/合规负责人 | review 免责声明、classify 对外材料风险 | 出具最终法律意见 |
| 管理层 | 判断融资目标和沟通范围 | 让 AI 直接对外招揽投资 |

必须由负责人或专业人员确认：融资目的、估值口径、融资条款、风险披露、对外版本、投资者沟通范围和所有承诺性表述。

## 输入资料

- [虚构公司画像](/course-c/examples/virtual-company-profile)。
- Week 05 销售渠道计划、Week 07 KPI 字典和 sample 经营指标。

## AI 工作流

### 第一步：BP 证据目录

```text
请为星河咖啡设备的区域扩张融资评审生成 BP 目录。
每章写清：要回答的问题、需要的证据、已有资料、缺口、负责人。
不要生成融资承诺、收益承诺或最终交易条款。
```

### 第二步：尽调清单

```text
请把以下材料整理成尽调清单。
分类：公司资料、产品资料、市场资料、客户资料、财务资料、法律合规、风险因素。
字段：资料名称、用途、来源、是否 sample/公开/脱敏、缺口、负责人、复核状态。
```

### 第三步：路演 Q&A 草稿

```text
请基于 BP 草稿生成路演 Q&A。
要求：
1. 问题覆盖市场、产品、收入、成本、竞争、风险、资金用途。
2. 回答只能引用已给资料。
3. 对缺失资料写“待负责人确认”。
4. 不写最终估值、融资条款、收益承诺或招揽语言。
```

### 第四步：材料一致性审查

```text
请审查 BP、财务摘要和 Q&A 是否一致。
输出：不一致字段、出现位置、可能原因、需要人工确认的问题、建议改法。
不要自行改写最终披露口径。
```

## 工具与应用整合

| 工具 | 用途 | 证据 |
|---|---|---|
| 文档工具 | BP 章节和版本控制 | 修订记录 |
| 表格工具 | 尽调清单、资金用途和数据来源表 | 字段表 |
| 演示工具 | 路演页结构草稿 | 截图或导出文件 |
| AI 工具 | draft 目录、prepare checklists、review 一致性 | Prompt 和人工修改 |
| 审计日志 | 记录材料版本、来源和审批 | [审计日志模板](/course-c/templates/audit-log) |

所有对外材料必须经过业务、财务、法务或合规负责人确认。AI 只处理结构、问题和证据，不生成最终投资邀约。

## Reference 使用

### 实现来源

- 文档、演示、表格工具说明：用于组织 BP、尽调清单和版本控制。
- 数据室或文件管理工具文档：用于权限、目录和审计记录。
- [工作流 SOP 模板](/course-c/templates/workflow-sop)：用于定义资料收集、复核和审批流程。
- [审计日志模板](/course-c/templates/audit-log)：用于记录材料来源和人工修改。

### 权威领域来源

- 公司金融教材、Damodaran 估值材料、Brealey/Myers/Allen 的 Corporate Finance 可支持资金成本、估值假设和融资结构的概念框架。
- Rosenbaum & Pearl 的 Investment Banking 可作为估值、可比公司和交易流程的学习来源，但课堂练习不能替代专业投行、律师或会计师意见。
- 公开招股书、年报和 SEC/交易所披露文件可作为风险因素、管理层讨论和资金用途表达样例。
- 证券监管、投资者保护或合规材料可用于识别招揽、承诺收益和重大遗漏风险。

## 合规审查

| 门 | 检查问题 |
|---|---|
| 数据门 | 财务、客户、投资者和合同资料是否为 fictional、sample、公开或脱敏？ |
| 来源门 | BP 每个数字、图表和风险是否能追溯到来源？ |
| 人类门 | 最终估值、融资条款、风险披露和对外版本是否由负责人或专业人员确认？ |
| 审计门 | 是否保存版本、Prompt、AI 输出、人工修改、审批记录和发布范围？ |

AI 可以支持 draft、analyze、organize、compare、review、summarize、classify、generate questions、prepare checklists、record workflow evidence。AI 不能直接做最终估值、融资条款、投资承诺、招揽文本、法律意见或材料签发。

## 助理包更新

更新投行业务材料助理：

- 新增工作流：BP 目录 -> 尽调清单 -> 路演 Q&A -> 一致性审查 -> 审批记录。
- 新增提示词：BP 证据目录、尽调资料缺口、Q&A 风险边界、材料一致性审查。
- 新增模板：尽调清单、融资材料审计表、对外材料审批记录。
- 新增禁用词审查：最终估值、保证收益、确定融资、无风险、立即认购、内部消息。

## 验收标准

- BP 结构能说明市场、产品、收入、成本、销售计划、风险和资金用途。
- 尽调清单至少覆盖公司、产品、市场、客户、财务、法律合规和风险因素。
- 路演 Q&A 对缺失资料标注“待负责人确认”。
- 明确禁止 AI 生成最终估值、融资条款、招揽文本和收益承诺。
- 至少引用 1 个公司金融、投行业务或证券披露权威领域来源。
