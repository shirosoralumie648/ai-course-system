## 业务情境

星河咖啡设备准备了解公开市场上“设备销售 + 耗材订阅 + 服务维护”模式的可比公司。投资研究助理需要做一份内部学习材料，帮助管理层理解公开披露信息、业务风险和需要继续追问的问题。

本周的输出不是股票推荐，而是研究框架：

| 模块 | 要回答的问题 | 证据来源 |
|---|---|---|
| 公司概况 | 公司靠什么业务赚钱？ | 年报、10-K、招股书、官网公开资料 |
| 财务表现 | 收入、毛利、现金流有什么变化？ | 公开财报、EDGAR filing、交易所公告 |
| 业务风险 | 供应链、客户集中、订阅续费有什么风险？ | 风险因素、管理层讨论、公开新闻 |
| 估值口径 | 市值、收入倍数、利润倍数如何计算？ | 公开价格数据和财报字段 |
| 待确认问题 | 哪些信息不能从公开资料直接证明？ | 来源表和人工批注 |

## 角色边界

| 角色 | AI 可以支持 | AI 不能直接做 |
|---|---|---|
| 投资研究助理 | 整理公开披露、比较口径、summarize 风险因素、prepare checklists | 给出买入、卖出、持有或仓位建议 |
| 财务分析人员 | review 财务字段、classify 收入和成本、generate questions | 做最终估值、目标价或投资评级 |
| 业务负责人 | compare 可比业务模式、analyze 风险问题 | 把 AI 草稿当成投资决策依据 |
| 合规负责人 | organize 来源表、record workflow evidence | 放行未经审查的对外投资材料 |

必须由负责人或专业人员确认：研究目的、来源可靠性、财务口径、风险解释、对外传播范围和任何涉及投资判断的文字。

## 输入资料

- 公开公司年报、季报、招股书、交易所公告或 SEC EDGAR filing。
- SEC Investor.gov 的投资教育材料和 EDGAR 使用说明。
- FINRA investor education 的风险、尽调和防欺诈材料。
- 公开市场价格数据截图或 sample 表格。
- [合规检查清单](/course-c/templates/compliance-checklist)。
- [审计日志模板](/course-c/templates/audit-log)。

不要上传真实证券账户、交易记录、持仓截图、身份证件、客户资产信息或未公开公司资料。

## AI 工作流

### 第一步：研究边界声明

```text
请为一份内部公开股票研究练习写研究边界声明。
要求：
1. 明确这不是投资建议。
2. 不输出买入、卖出、持有、目标价或仓位建议。
3. 只使用公开披露、官方教育材料和人工提供的 sample 表格。
4. 列出必须由负责人或专业人员确认的内容。
```

### 第二步：公开披露来源表

```text
请把以下公开资料整理成来源表。
字段：来源名称、发布机构、发布日期、链接或文件名、涉及问题、可引用内容、不能推出的结论、复核人。
请标记 SEC、EDGAR、FINRA、公司官网、交易所公告和媒体资料的来源类型。
```

### 第三步：业务与财务拆解

```text
请基于公开披露资料，整理公司的业务和财务观察。
结构：
- 收入来源
- 成本和毛利线索
- 现金流和负债线索
- 风险因素
- 管理层讨论中需要继续追问的问题
不要输出投资评级、买卖建议或最终估值。
```

### 第四步：风险备忘录

```text
请生成一份内部风险备忘录草稿。
每条风险必须包含：证据来源、原文位置、AI 摘要、人工复核问题、是否可对外引用。
结尾写“本备忘录不构成买卖建议”。
```

## 工具与应用整合

| 工具 | 用途 | 证据 |
|---|---|---|
| SEC EDGAR 或交易所披露系统 | 查找公开 filing | 来源表和截图 |
| 表格工具 | 记录指标、来源和复核状态 | 字段表 |
| 文档工具 | 生成研究框架和风险备忘录 | 版本记录 |
| AI 工具 | draft 摘要、analyze 风险、compare 口径 | Prompt、输出和人工修改 |
| 审计日志 | 记录资料来源、修改理由和审批 | [审计日志模板](/course-c/templates/audit-log) |

工具只能帮助收集、整理和解释公开资料。任何投资判断、对外材料和管理层引用都要经过人工审阅。

## Reference 使用

### 实现来源

- SEC EDGAR、交易所披露平台或公司投资者关系页面的帮助文档：用于学习如何查找公开披露文件。
- 表格、文档和 PDF 批注工具说明：用于保存来源表、页码和批注。
- [合规检查清单](/course-c/templates/compliance-checklist)：用于执行数据门、来源门、人类门和审计门。
- [审计日志模板](/course-c/templates/audit-log)：用于记录研究过程证据。

### 权威领域来源

- SEC Investor.gov 的投资教育和 EDGAR 资料说明公开披露、风险提示和投资者保护边界。
- FINRA investor education 可作为尽调、风险识别和防欺诈教育来源。
- 公开公司年报、10-K、招股书和交易所公告是业务和风险事实的主要来源。
- Graham & Dodd 的 Security Analysis、CFA Institute 投资分析教材或公司金融教材可支持财务分析框架，但不能替代持牌或合格专业人员判断。

## 合规审查

| 门 | 检查问题 |
|---|---|
| 数据门 | 是否只使用公开、sample、虚构或脱敏资料？是否排除个人账户和持仓信息？ |
| 来源门 | 每个结论是否有 filing、公告、官方教育材料或权威教材来源？ |
| 人类门 | 风险解释、财务口径和发布范围是否由负责人或专业人员确认？ |
| 审计门 | 是否保存来源表、Prompt、AI 输出、人工修改和审批记录？ |

AI 可以支持 draft、analyze、organize、compare、review、summarize、classify、generate questions、prepare checklists、record workflow evidence。AI 不能直接做买卖建议、目标价、最终估值、投资评级、仓位配置或对外招揽。

## 助理包更新

更新投资研究助理：

- 新增工作流：研究边界 -> 来源表 -> 业务拆解 -> 风险备忘录 -> 合规复核。
- 新增提示词：无建议声明、EDGAR 来源表、风险因素摘要、复核问题清单。
- 新增模板：公开披露来源表、风险备忘录、无投资建议声明。
- 新增审计规则：任何“买入、卖出、持有、目标价、推荐、仓位”都必须删除或改写为待确认问题。

## 验收标准

- 研究框架至少覆盖公司概况、财务表现、业务风险、估值口径和待确认问题。
- 来源表区分 SEC、EDGAR、FINRA、公开披露、媒体和教材来源。
- 风险备忘录每条风险都有证据来源和人工复核问题。
- 明确写出“不构成买卖建议”，并禁止 AI 输出买入、卖出、持有和目标价。
- 至少引用 1 个官方/监管来源和 1 个投资分析或公司金融权威领域来源。
