# 工作流 SOP 模板

> 工作流 SOP 把一次业务操作变成可重复、可审批、可审计的步骤。

## 用途

用于描述一个岗位任务从输入到输出的标准流程，明确 AI 负责什么、人负责什么、风险在哪里、证据保留在哪里。

## 适用场景

| 场景 | 示例 |
|---|---|
| 销售跟进 | 会议纪要转 CRM 字段和后续行动 |
| 财务分析 | 样例预算表转部门预算说明 |
| HR 招聘 | 岗位说明转筛选表和面试题库 |
| 法务合同 | 合同样例转风险清单和待确认问题 |

## 必填字段

| 字段 | 说明 |
|---|---|
| 触发条件 | 什么时候启动这个流程 |
| 输入 | 需要哪些资料、表格、会议纪要或公开来源 |
| 步骤 | AI 和人工各做什么 |
| 输出 | 最终交付什么格式 |
| 负责人 | 谁执行 |
| 审批人 | 谁确认 |
| 风险等级 | 低 / 中 / 高 |
| 证据 | 保留哪些输入、输出、修改和审批记录 |

## 示例片段

```markdown
## 基本信息
- SOP 名称：销售会议纪要转 CRM 跟进流程
- 岗位：星河咖啡设备销售运营
- 触发条件：客户会议结束后 24 小时内
- 业务目标：形成 CRM 字段、客户需求摘要、下一步行动和风险提示
- 风险等级：中
```

## 使用检查

- [ ] 触发条件足够具体，不是"需要时"。
- [ ] 输入材料写清来源和是否脱敏/合成。
- [ ] 步骤区分 AI 操作和人工操作。
- [ ] 输出格式可检查。
- [ ] 审批人和审批时点明确。
- [ ] 有输入、AI 输出、人工修改和最终版本证据。
