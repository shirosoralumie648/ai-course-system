# 合规检查清单模板

> 合规检查清单把风险控制放进每次 AI 工作流，而不是等到最后补一句免责声明。

## 用途

用于检查 AI 参与业务任务时，数据、来源、人工审批和审计记录是否达到课程要求。

## 适用场景

| 风险等级 | 典型任务 | 要求 |
|---|---|---|
| 低 | 格式整理、公开资料摘要、内部草稿 | 标注来源，保留修改记录 |
| 中 | 客户材料、销售跟进、预算说明、招聘材料 | 做四门检查，负责人复核 |
| 高 | 投资、投行、税务、法务、HR 决策、财务结论、企业系统连接 | 专业人员或管理者审批，不能让 AI 做最终决定 |

## 必填字段

| 字段 | 说明 |
|---|---|
| 风险等级 | 低 / 中 / 高 |
| 数据敏感度 | 公开 / 内部 / 脱敏 / 合成 |
| 数据门 | 输入资料是否可给 AI 使用 |
| 来源门 | 结论依据来自哪里 |
| 人类门 | 谁审批、什么时候审批 |
| 审计门 | 输入、输出、修改和最终版本在哪里 |
| 来源类型 | 实现来源 / 权威领域来源 / 公开资料 / 内部规则 |
| 审批人角色 | 负责人、财务、法务、HR、管理者等 |
| 审批时点 | 草稿前、发布前、提交前、归档前 |
| 审计证据 | 文件、截图、表格、版本记录或审批记录 |
| 发布边界 | 可内部使用、可给客户、可公开、不可发布 |

```markdown
## 数据门
- 输入资料类型：
- 数据敏感度：
- 是否包含客户/员工/财务/合同/税务/凭证/系统数据：

- 是否允许进入 AI 工具：

## 来源门
- 实现来源：
- 权威领域来源：
- 事实：
- 假设：
- AI 推论：

## 人类门
- 审批人角色：
- 审批时点：
- 必须人工确认的问题：
- AI 不得直接决定的事项：

## 审计门
- 输入材料归档位置：
- AI 输出归档位置：
- 人工修改记录：
- 审批记录：
- 最终版本：
- 留存期限或复盘时间：
```

## 示例片段

```markdown
## 任务信息
- 任务名称：销售漏斗周报草稿
- 岗位：星河咖啡设备销售运营
- 输出物：销售漏斗表 + 下周跟进建议
- 风险等级：中
- 发布边界：销售团队内部使用，客户报价必须由销售负责人确认
```

## 使用检查

- [ ] 风险等级和发布边界已填写。
- [ ] 数据门说明资料是否公开、内部、脱敏或合成。
- [ ] 来源门区分事实、假设、AI 推论和待确认问题。
- [ ] 人类门写清审批人角色和审批时点。
- [ ] 审计门能追溯输入、输出、人工修改、审批和最终版本。
- [ ] 高风险任务没有把 AI 描述成最终专业判断者。
