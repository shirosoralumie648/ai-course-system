# 提示词库模板

> 提示词库不是 prompt 收藏夹。每条提示词都要绑定岗位任务、输入资料、输出格式、来源要求和人工复核规则。

## 用途

用于沉淀可复用任务提示词、审查提示词和复盘提示词，让同岗位的人可以稳定生成相近质量的业务输出。

## 适用场景

| 类型 | 用途 |
|---|---|
| 任务提示词 | 让 AI 生成报告、表格、清单、邮件、会议纪要或分析框架 |
| 审查提示词 | 让 AI 检查来源、逻辑、风险、格式和遗漏项 |
| 复盘提示词 | 让 AI 总结失败样本、人工修改原因和下次改进 |

## 必填字段

| 字段 | 说明 |
|---|---|
| 任务目标 | 这条提示词解决哪个业务动作 |
| 上下文 | 岗位、业务情境和约束 |
| 输入 | 需要粘贴或引用哪些材料 |
| 输出格式 | 表格、报告、清单、邮件、PPT 大纲等 |
| 来源要求 | 需要实现来源、权威领域来源或公开资料 |
| 人工复核 | 谁看、看什么、什么时候确认 |
| 复用备注 | 适合什么情况，不适合什么情况 |

## 可复制模板

```markdown
# 提示词卡片

## 基本信息
- 编号：
- 名称：
- 类型：任务 / 审查 / 复盘
- 适用岗位：
- 关联工作流：

## 提示词
你是【岗位/角色】。请基于【输入资料】完成【任务目标】。

背景：
- 公司/业务：
- 当前问题：
- 不能越过的边界：

输入资料：
- 资料 1：
- 资料 2：

输出要求：
- 格式：
- 字段：
- 需要区分事实、假设、推论和建议：
- 需要列出待人工确认问题：

来源要求：
- 实现来源：
- 权威领域来源：

人工复核：
- 复核人：
- 必查项：
- 不允许直接发布的内容：

## 复用备注
- 适合：
- 不适合：
- 常见失败：
```

## 示例片段

```markdown
## 基本信息
- 编号：P-SALES-01
- 名称：客户会议纪要转跟进行动
- 类型：任务
- 适用岗位：星河咖啡设备销售运营
- 关联工作流：销售会议纪要转 CRM 跟进流程
```

## 使用检查

- [ ] 提示词说明岗位和业务场景。
- [ ] 输入资料不是空泛的"相关资料"。
- [ ] 输出格式具体到字段或段落结构。
- [ ] 要求区分事实、假设、推论和建议。
- [ ] 写清哪些内容必须人工复核。
- [ ] 记录这条提示词不适合的场景。
