# 岗位 AI 助理包模板

> 岗位 AI 助理包是 Course C 的核心成果。它让同岗位的人可以复用你的工作流，而不是只看到一次聊天记录。

## 用途

用来汇总一个岗位的 AI 工作资产，包括角色画像、工作流、提示词、Skills 或 SOP、模板、数据、工具、合规材料和案例。

## 适用场景

| 场景 | 使用方式 |
|---|---|
| 每周课程输出 | 每周新增一个工作流、提示词、模板或合规材料 |
| 期末项目 | 作为最终提交的主包结构 |
| 企业内训 | 让同岗位同事按统一方法复用 AI 工作流 |

## 必填字段

| 字段 | 说明 |
|---|---|
| 角色画像 | 岗位职责、业务目标、不能越过的边界 |
| 工作流 | 至少 3 个可重复执行的任务流程 |
| 提示词 | 任务提示词、审查提示词、复盘提示词 |
| Skills 或 SOP | 可让 AI 或人按步骤执行的规则 |
| 模板 | 报告、表格、邮件、会议纪要、检查清单等 |
| 数据 | 样例字段、公开数据、脱敏数据或合成数据 |
| 工具 | 办公工具、业务 SaaS、AI 工具、API/MCP 计划 |
| 合规 | 数据门、来源门、人类门、审计门 |
| 案例 | 改造前后证据、失败样本和人工修改记录 |

## 示例片段

```markdown
## 角色画像
- 岗位：虚构公司「星河咖啡设备」销售运营
- 业务目标：把线索分层、会议纪要和跟进动作整理成可复用 CRM 流程
- 常见输入：sample CRM 表、客户会议纪要、渠道活动记录
- 常见输出：线索分层表、跟进邮件、销售漏斗周报
- 必须人工审批的事项：价格承诺、合同条款、客户投诉升级
- AI 不能直接做的事项：承诺折扣、代表销售负责人签署合同
```

## 使用检查

- [ ] 角色画像写清楚输入、输出和审批人。
- [ ] 至少 3 个工作流能被别人按步骤执行。
- [ ] 提示词不是孤立列表，能对应到具体工作流。
- [ ] 数据来源、脱敏或合成状态清楚。
- [ ] 合规材料覆盖数据门、来源门、人类门、审计门。
- [ ] 案例包含改造前后证据，而不是只写效果描述。
