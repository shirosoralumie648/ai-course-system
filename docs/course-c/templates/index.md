# 课程 C 模板与样例

> 这里放的是 Course C 的可复用工作资产。模板不是作业装饰，而是后续每周把 AI 工作流沉淀进岗位 AI 助理包的最小结构。

## 使用方式

每个模板都服务于一个重复业务动作：定义岗位、拆工作流、沉淀提示词、做合规检查、记录审计证据、证明改造效果。

| 模板 | 用途 | 适合阶段 |
|---|---|---|
| [岗位 AI 助理包](/course-c/templates/role-ai-assistant-pack) | 汇总一个岗位的角色、工作流、提示词、工具、数据和案例 | Week 01 起持续更新 |
| [工作流 SOP](/course-c/templates/workflow-sop) | 把一个业务任务拆成可重复执行、可审批、可审计的流程 | 每周输出和期末项目 |
| [提示词库](/course-c/templates/prompt-library) | 管理可复用任务提示词、审查提示词和复盘提示词 | 每周助理包更新 |
| [合规检查清单](/course-c/templates/compliance-checklist) | 用数据门、来源门、人类门、审计门检查风险 | 高风险任务和期末项目 |
| [审计日志](/course-c/templates/audit-log) | 记录输入、AI 输出、人工修改、审批和最终版本 | 每次交付前后 |
| [ROI 报告](/course-c/templates/roi-report) | 证明时间、质量、风险或一致性改进 | Week 16 答辩 |

## 最低提交规则

每次使用模板时，至少保留三类证据：

1. 输入材料：样例、公开资料、脱敏资料或业务规则。
2. AI 工作流：提示词、输出、人工修改和失败样本。
3. 审查记录：来源、审批人、审计证据和最终版本。

## 和样例数据配合

模板可以配合 [合成样例包](/course-c/examples/) 使用。样例包提供虚构公司、CRM、财务、HR 和合同纠纷材料，适合课堂练习和低风险演示。

## 不能怎么用

- 不要把模板当成聊天记录整理表。
- 不要用课堂外部业务对象、人员、合同、财务、税务或凭证数据直接填入公开作业。
- 不要把 AI 输出当成法律、税务、投资、HR、财务或管理最终结论。
- 不要只堆 prompt；每个 prompt 必须回到岗位任务、输入、输出和审查证据。

## 快速选择

| 你要做什么 | 从哪个模板开始 |
|---|---|
| 为一个岗位建立完整助理包 | 岗位 AI 助理包 |
| 把重复工作变成稳定流程 | 工作流 SOP |
| 保存可复用提示词 | 提示词库 |
| 检查高风险任务 | 合规检查清单 |
| 留下可复盘证据 | 审计日志 |
| 说明改造是否有效 | ROI 报告 |
