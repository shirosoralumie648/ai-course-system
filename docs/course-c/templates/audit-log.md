# 审计日志模板

> 审计日志回答一个问题：这份 AI 辅助输出从哪里来、怎么改、谁确认、最终用了哪个版本。

## 用途

用于记录 AI 工作流中的输入、AI 输出、人工修改、审批、最终版本和保留规则，让工作可复盘。

## 适用场景

| 场景 | 记录重点 |
|---|---|
| 报告草稿 | 来源、AI 总结、人工修改、最终发布版本 |
| 客户材料 | 客户数据处理、审批记录、对外发送版本 |
| 财务/税务/法务/HR | 专业人员确认、限制说明、不可直接发布内容 |
| 企业系统连接计划 | 权限、只读范围、日志、回滚和人工确认 |

## 必填字段

| 字段 | 说明 |
|---|---|
| 输入 | 原始资料、样例资料、公开资料或脱敏资料 |
| AI 输出 | 模型生成的草稿、表格、清单或建议 |
| 人工修改 | 人改了什么，为什么改 |
| 审批 | 谁审批，通过或退回 |
| 最终版本 | 最后交付或归档的文件 |
| 留存 | 文件保存位置和复盘时间 |

## 示例片段

```markdown
## 人工修改记录
| 修改人 | 修改内容 | 修改原因 | 影响 |
|---|---|---|---|
| 销售负责人 | 删除 AI 生成的折扣承诺 | 折扣需要单独审批 | 输出仅保留跟进建议 |
```

## 使用检查

- [ ] 输入材料能追溯来源和数据状态。
- [ ] AI 输出记录包含工具/模型和提示词编号。
- [ ] 人工修改写清原因。
- [ ] 审批记录写清角色和结论。
- [ ] 最终版本有发布边界。
- [ ] 高风险任务有留存位置和复盘时间。
