## 业务情境

管理者想知道全国渠道扩张是否健康。数据分析助理要把销售、维护、耗材订阅和客户反馈整理成管理仪表盘。

先定义管理问题：

| 管理问题 | 可观察指标 | 不能直接推出 |
|---|---|---|
| 渠道是否有效 | 新增线索、有效会议、试点数量 | 不能直接推出未来收入 |
| 服务是否稳定 | 维护响应时长、故障次数 | 不能直接推出客户满意度 |
| 订阅是否增长 | 耗材续订率、订阅金额 | 不能直接推出利润 |
| 销售是否推进 | 漏斗阶段、跟进时效 | 不能直接推出签约概率 |

## 角色边界

| 角色 | 可以做 | 必须人工确认 |
|---|---|---|
| 数据分析助理 | 设计指标字典、仪表盘字段、异常说明草稿 | 指标口径、经营解释、管理结论 |
| 运营数据组 | 清洗样例数据、维护字段口径 | 数据质量 |
| 销售/售后负责人 | 确认业务含义和异常原因 | 行动建议 |
| 管理者 | 决定资源调整和经营动作 | 最终管理判断 |

## AI 工作流

### 第一步：KPI 树

```text
请基于星河咖啡设备的虚构业务目标，设计一棵 KPI 树。
顶层目标：全国渠道扩张是否健康。
要求：
1. 分成销售、服务、订阅、客户反馈四类。
2. 每个指标写定义、数据来源、负责人。
3. 标出不能直接推出的管理结论。
```

### 第二步：指标字典

```text
请把以下 KPI 表整理成指标字典。
字段：指标名称、业务含义、计算口径、数据来源、更新频率、负责人、常见误读、需要人工确认的问题。
```

### 第三步：仪表盘说明

```text
请生成管理仪表盘说明草稿。
结构：
1. 本月变化
2. 可能原因
3. 数据限制
4. 待负责人确认的问题
5. 不建议直接得出的结论
不要写最终经营建议。
```

## Reference 使用

### 实现来源

- 表格、BI 或可视化工具文档：说明图表、筛选和导出方式。
- [ROI 报告模板](/course-c/templates/roi-report)：用于记录时间、质量、风险或一致性改进。
- [合规检查清单](/course-c/templates/compliance-checklist)：用于审查指标解释和发布边界。

### 权威领域来源

- Kaplan & Norton (1992) 的 Balanced Scorecard / 平衡计分卡提醒学生从多个维度看管理表现，而不是只看单一数字。
- Analytics management / 数据分析管理资料可支持指标治理、数据质量和业务解释流程。
- 统计和数据质量基础可帮助识别样本偏差、口径变更和异常值，但不能替代业务负责人判断。

## 合规审查

| 门 | 检查问题 |
|---|---|
| 数据门 | KPI 是否为 sample、公开、脱敏或虚构？ |
| 来源门 | 每个指标是否有口径、来源和负责人？ |
| 人类门 | 异常解释和管理结论是否由负责人确认？ |
| 审计门 | 是否保存数据版本、AI 解释、人工修改和最终仪表盘说明？ |

AI 可以生成指标解释草稿，不直接做资源调整、绩效评价或经营结论。

## 验收标准

- KPI 树至少覆盖销售、服务、订阅和客户反馈四类。
- 指标字典写清定义、来源、更新频率、负责人和常见误读。
- 仪表盘说明区分事实、可能原因、限制和待确认问题。
- 至少引用 1 个管理指标、平衡计分卡、分析管理或数据质量权威领域来源。
- 没有让 AI 直接做最终经营判断。
