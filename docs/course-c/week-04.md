## 业务情境

市场部准备做一组“办公室咖啡体验升级”内容，面向联合办公空间、酒店和企业茶水间负责人。品牌内容助理要把产品定位转成内容资产：

| 资产 | 用途 | 审查重点 |
|---|---|---|
| 品牌声音指南 | 统一表达方式 | 不能夸大服务能力 |
| 活动主题 | 让销售和市场共用 | 不能承诺未确认价格和交付 |
| 内容日历 | 排期公众号、海报、短视频脚本 | 不能混用无来源数据 |
| 发布清单 | 对外发布前复核 | 负责人确认 |

## 角色边界

| 角色 | 可以做 | 必须人工确认 |
|---|---|---|
| 品牌内容助理 | 草拟品牌语气、内容主题、海报文案、视频脚本 | 事实准确性、对外承诺、品牌调性 |
| 市场负责人 | 审查活动主题和发布节奏 | 是否代表公司正式对外表达 |
| 销售负责人 | 审查客户痛点和销售话术 | 是否涉及价格、交付、合同承诺 |
| 法务/管理者 | 仅在敏感表达时介入 | 是否涉及争议性或合规风险 |

## AI 工作流

### 第一步：品牌声音指南

```text
请基于以下产品定位，为星河咖啡设备的“联合办公空间咖啡站服务包”生成品牌声音指南。
字段：
- 目标受众
- 品牌关键词
- 推荐语气
- 禁止表达
- 可用证据
- 需要人工确认的表达
输出为 Markdown 表格。
```

### 第二步：内容日历

```text
请生成 4 周内容日历。
每周包含：主题、目标受众、核心信息、内容形式、输入资料、发布前检查项。
不要写价格承诺、绝对化效果或未经确认的数据。
```

### 第三步：发布审查

```text
请审查以下品牌文案。
按表格输出：原句、风险类型、为什么有风险、建议修改、需要谁确认。
风险类型包括：事实无来源、夸大承诺、价格/交付承诺、客户隐私、品牌调性不一致。
```

## Reference 使用

### 实现来源

- [提示词库模板](/course-c/templates/prompt-library)：保存品牌生成提示词和审查提示词。
- [审计日志模板](/course-c/templates/audit-log)：记录发布前人工修改和审批。
- 平台内容规范或设计工具文档：说明素材格式和发布限制。

### 权威领域来源

- Keller (1993) 的 customer-based brand equity / 品牌资产框架可帮助学生理解品牌知识、联想和一致性，但不能证明某条文案一定带来转化。
- 品牌管理或整合营销传播教材可支持内容日历、渠道、受众和信息一致性设计。
- 平台广告规范可作为发布边界来源，但不能替代公司内部品牌审批。

## 合规审查

| 门 | 检查问题 |
|---|---|
| 数据门 | 是否只使用虚构、sample、公开或脱敏素材？ |
| 来源门 | 文案里的事实和数据是否有来源？ |
| 人类门 | 市场负责人是否确认对外发布版本？ |
| 审计门 | 是否保存 AI 草稿、人工修改、审批记录和最终稿？ |

AI 可以草拟和复核内容，不直接发布品牌材料。

## 助理包更新

更新品牌内容助理：

- 新增工作流：定位文档 -> 品牌声音指南 -> 内容日历 -> 发布审查。
- 新增提示词：品牌语气、内容日历、文案风险审查。
- 新增模板：发布前审查清单。
- 新增案例：办公室咖啡体验升级活动。

## 验收标准

- 品牌声音指南包含目标受众、语气、禁止表达和审核角色。
- 内容日历至少 4 周，每条内容都有输入资料和发布前检查项。
- 至少 1 个海报文案或视频脚本经过 AI 草拟和人工修改。
- 至少引用 1 个品牌管理或整合营销传播权威领域来源。
- 发布审查清单明确数据门、来源门、人类门、审计门。
