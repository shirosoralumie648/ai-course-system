# Lab 16：assistant-pack 终稿与答辩证据包

<ChapterIntroduction duration="约 2-3 小时" output="assistant-pack 终稿 + before-state/after-state 报告 + 合规证据包 + 答辩材料" prerequisite="完成 Week 16" :tags="['assistant-pack', 'before-state', 'after-state', '答辩']">

本实验是课程 C 的最终提交。你要把一个岗位 AI 助理包整理到别人能复用的程度，并用证据证明一个工作流被真实或 realistic 地改造。

</ChapterIntroduction>

## 实验目标

- 完成 assistant-pack 终稿。
- 输出 before-state / after-state 工作流改造报告。
- 组装数据门、来源门、人类门、审计门合规证据包。
- 准备 5-8 分钟答辩材料和追问应答。

## 实验任务

选择一个岗位方向，提交完整的课程 C 最终项目包。

必须交付：

| 产物 | 要求 |
|---|---|
| assistant-pack manifest | 角色画像、工作流、prompts、templates、tools、data、compliance、cases |
| before-state / after-state 报告 | 原流程、痛点、新流程、AI 支持方式、人工审批、改进证据 |
| 合规证据包 | 数据门、来源门、人类门、审计门，每项有文件或记录 |
| Reference evidence map | 实现来源和权威领域来源分开列出 |
| ROI / quality / risk proof | 至少一种可检查改进证据 |
| defense deck | 5-8 分钟展示，含限制和下一步 |

## 输入材料

- Week 01-15 的周产物和实验产物。
- Week 16 的答辩组织方法。
- [期末项目要求](/course-c/final-project)。
- [课程 C 评分标准](/course-c/rubric)。
- [合规检查清单](/course-c/templates/compliance-checklist)。
- [审计日志模板](/course-c/templates/audit-log)。
- [ROI 报告模板](/course-c/templates/roi-report)。

所有公开提交材料必须脱敏。不要提交真实客户、员工、财务、税务、合同、凭证、密钥、OAuth token、生产系统导出或内部未授权材料。

## 操作步骤

1. 选择一个岗位和一个核心业务流程。
2. 整理 assistant-pack 目录，删除重复、无来源或不可复用的 prompt。
3. 写 `assistant-pack-manifest.md`，列出每个文件用途、来源、适用边界。
4. 写 `before-after-workflow-report.md`，展示 before-state、after-state、人工审批和改进证据。
5. 建立 `reference-evidence-map.md`，分开列实现来源和权威领域来源。
6. 建立 `compliance-evidence-packet.md`，填数据门、来源门、人类门、审计门。
7. 用 `roi-quality-risk-proof.md` 说明时间、质量、错误减少、风险可见性或一致性证据。
8. 生成 defense deck 和 5-8 分钟讲稿。
9. 让 AI 生成评委追问清单，再人工回答每个高风险边界问题。
10. 更新岗位 AI 助理包，确保最终版本能被同岗位的人复用。

## 提交要求

- `assistant-pack-manifest.md`。
- `before-after-workflow-report.md`。
- `reference-evidence-map.md`。
- `compliance-evidence-packet.md`。
- `roi-quality-risk-proof.md`。
- `defense-deck.pdf` 或 `defense-deck.md`。
- `defense-script.md`。
- `reviewer-questions-and-answers.md`。
- 完整岗位 AI 助理包目录。

## 验收标准

- assistant-pack 至少包含 3 个工作流、5 个 prompts、3 个 templates、工具清单、数据结构、合规材料和案例证据。
- before-state / after-state 报告能说明原流程、AI 支持方式、人工审批点、风险控制和改进证据。
- 合规证据包有数据门、来源门、人类门、审计门记录。
- Reference evidence map 同时包含实现来源和权威领域来源。
- ROI / quality / risk proof 至少有一种可检查证据。
- 答辩材料没有伪造证据，没有把 AI 当作最终专业判断者。

## 评分标准

| 维度 | 分值 | 说明 |
|---|---:|---|
| assistant-pack 完整性 | 25 | 结构完整、可复用、边界清楚 |
| 工作流改造证据 | 25 | before-state、after-state 和改进证明清楚 |
| 合规与来源 | 25 | 四门证据和 Reference evidence map 完整 |
| 答辩表达 | 15 | 5-8 分钟内讲清流程、证据、限制和下一步 |
| 复盘质量 | 10 | 能说明失败样本、人工修改和后续改进 |
