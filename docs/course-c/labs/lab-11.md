# Lab 11：税务资料清单与留档 SOP

<ChapterIntroduction duration="约 2 小时" output="税务资料清单 + 留档 SOP + 风险问题清单 + 禁止动作检查" prerequisite="完成 Week 11" :tags="['税务', '资料清单', '留档 SOP', '合规审计']">

本实验只做税务资料准备和合规留档。任何申报口径、税额、抵扣、调整和提交动作都必须由税务负责人或专业人员确认。

</ChapterIntroduction>

## 实验目标

- 建立季度税务资料清单。
- 编写税务资料留档 SOP。
- 生成税务负责人复核问题。
- 更新税务合规助理包。

## 实验任务

为星河咖啡设备准备一份 fictional / sample 季度税务资料包。

必须交付：

| 产物 | 要求 |
|---|---|
| 税务资料清单 | 收入、成本费用、发票、工资、固定资产、供应商、合同 |
| 留档 SOP | 收集、脱敏、来源核对、复核、审批、归档 |
| 风险问题清单 | 只列问题、证据和负责人 |
| 禁止动作检查 | 标出提交申报、确认税额等越界词 |
| 审计记录 | Prompt、人工修改、审批和归档记录 |

## 输入材料

- fictional / sample 收入表、费用表、发票登记表、工资汇总、固定资产清单。
- Week 10 成本分类和预算差异复核表。
- IRS official recordkeeping/business expense guidance 或本地税务机关公开资料。
- [合规检查清单](/course-c/templates/compliance-checklist)。
- [审计日志模板](/course-c/templates/audit-log)。

不要提交真实税号、发票原件、银行账号、工资明细、客户付款凭证、电子税务局账号、密码或验证码。

## 操作步骤

1. 写明资料包范围：只做准备和留档，不做税务申报。
2. 让 AI 生成税务资料清单，字段包含来源、负责人、缺口和复核状态。
3. 人工删除真实敏感字段，保留 sample 或脱敏说明。
4. 让 AI 生成留档 SOP。
5. 让 AI 生成税务负责人或顾问复核问题清单。
6. 运行禁止动作检查，标出提交申报、确认税额、可抵扣、纳税调整等越界词。
7. 用四门模型记录脱敏、来源、审批和审计证据。
8. 更新岗位 AI 助理包，加入税务资料准备和越界词审查。

## 验收标准

- 税务资料清单覆盖本实验要求的资料类别。
- 留档 SOP 写清每一步输入、输出、负责人和风险。
- 风险问题清单没有给最终税务建议。
- 数据门、来源门、人类门、审计门都有记录。
- 助理包新增税务资料准备、留档和禁止动作检查流程。
