## 业务情境

星河咖啡设备与一家渠道伙伴发生供货和服务响应争议。销售、售后和财务手里有合同、邮件、会议纪要、发货记录和付款记录。法律协作助理要把材料整理成律师可读的证据包。

本周产物是“协作材料”，不是“法律意见”：

| 材料 | AI 支持 | AI 不能直接做 |
|---|---|---|
| 合同条款清单 | classify 付款、交付、违约、保密条款 | 判断条款最终法律效力 |
| Issue spotting | generate questions | 出具最终法律意见 |
| 争议时间线 | organize 事实和证据 | 决定纠纷策略 |
| 证据包目录 | summarize 文件和来源 | 篡改或选择性删除证据 |
| 律师问题 | prepare checklists | 替律师给结论 |

## 角色边界

| 角色 | AI 可以支持 | AI 不能直接做 |
|---|---|---|
| 法律协作助理 | draft 条款清单、organize 时间线、summarize 证据 | 出具最终法律意见 |
| 业务负责人 | 补充事实和商业目标 | 让 AI 决定谈判或诉讼策略 |
| 法务/律师 | 判断法律风险和行动方案 | 被 AI 草稿替代 |
| 合规负责人 | review 证据保全和权限 | 放行未经审查的对外沟通 |

必须由负责人或专业人员确认：合同签署、条款解释、违约认定、赔偿主张、律师函、诉讼/仲裁策略、和解方案和对外沟通。

## 输入资料

## AI 工作流

### 第一步：合同条款检查清单

```text
请基于 sample 合同摘要生成条款检查清单。
分类：主体、付款、交付、验收、服务 SLA、违约、解除、保密、争议解决。
字段：条款位置、业务含义、风险问题、需要法务确认的问题。
不要给最终法律结论。
```

### 第二步：争议时间线

```text
请把以下合同纠纷材料整理成时间线。
字段：日期、事件、证据文件、涉及人员、事实陈述、AI 摘要、待确认问题。
要求事实和推论分开，不要决定责任归属。
```

### 第三步：证据包目录

```text
请生成律师审阅用证据包目录。
分类：合同文件、订单、交付记录、服务记录、付款记录、沟通记录、会议纪要。
每项写来源、完整性、权限、缺口和保全建议。
```

### 第四步：律师问题清单

```text
请生成给律师的问题清单。
分类：合同效力、履约事实、违约风险、证据缺口、沟通边界、可能程序。
不要提出诉讼策略、和解底线或最终法律意见。
```

## 工具与应用整合

| 工具 | 用途 | 证据 |
|---|---|---|
| 文档工具 | 条款清单、时间线和律师问题 | 版本记录 |
| 文件管理工具 | 证据包目录和权限 | 目录截图或权限表 |
| 合同管理工具 | 合同字段和审批记录 | read-only 字段表 |
| AI 工具 | classify 条款、summarize 证据、generate questions | Prompt 和人工修改 |
| 审计日志 | 记录来源、权限和审批 | [审计日志模板](/course-c/templates/audit-log) |

课堂练习不连接真实合同系统，不自动发送律师函，不代表公司对外沟通。

## 合规审查

| 门 | 检查问题 |
|---|---|
| 数据门 | 是否只使用 sample、虚构、公开或脱敏合同和纠纷资料？ |
| 来源门 | 每个条款、事件和证据是否有文件来源、位置和权限说明？ |
| 人类门 | 合同解释、法律意见、签署、纠纷策略和对外沟通是否由法务/律师/负责人确认？ |
| 审计门 | 是否保存 Prompt、AI 输出、人工修改、证据目录、权限和审批记录？ |

AI 可以支持 draft、analyze、organize、compare、review、summarize、classify、generate questions、prepare checklists、record workflow evidence。AI 不能直接做最终法律意见、合同签署、责任认定、律师函、诉讼/仲裁策略、和解底线或对外法律沟通。

## 助理包更新

更新法律协作助理：

- 新增工作流：合同条款清单 -> 争议时间线 -> 证据包目录 -> 律师问题 -> 法务审批。
- 新增提示词：条款检查、issue spotting、时间线、证据包、律师问题。
- 新增模板：合同条款检查表、争议时间线、证据包目录、律师问题清单。
- 新增审计规则：凡涉及法律意见、合同签署、纠纷策略和对外沟通，必须停止并转法务/律师。

## 验收标准

- 条款清单至少覆盖主体、付款、交付、验收、违约、保密和争议解决。
- 时间线区分事实、证据、AI 摘要和待确认问题。
- 证据包目录写清来源、权限、完整性和缺口。
- 至少引用 1 个合同法、法院/司法记录、法务实务或证据管理权威领域来源。
- 没有让 AI 直接给法律意见、签署合同或决定纠纷策略。
