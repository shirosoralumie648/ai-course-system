# 虚构合同纠纷样例：设备交付延期

> 本页是 fictional / 虚构合同与纠纷材料包。所有公司、合同、日期、金额和争议内容都是教学示例。

## 样例背景

| 项目 | 内容 |
|---|---|
| 甲方 | 示例客户-晨星酒店 |
| 乙方 | 星河咖啡设备有限公司（虚构） |
| 合同主题 | G-300 全自动咖啡站采购与维护服务 |
| 争议摘要 | 甲方认为交付延期影响开业准备，要求说明补救方案 |
| 风险等级 | 高 |
| 使用边界 | AI 只能整理材料、生成问题清单和风险备忘录草稿，不能给最终法律意见 |

## 条款摘录（虚构）

```text
第 4 条 交付安排：乙方应在样例订单确认后 30 个工作日内完成设备交付和初次调试。
第 7 条 服务支持：乙方应提供 12 个月样例维护服务，具体响应时间以双方确认的服务单为准。
第 9 条 争议处理：双方应先通过业务沟通解决；无法解决时，再提交合同约定的争议处理程序。
```

## AI 辅助任务

1. 把材料整理成时间线。
2. 标出需要人工确认的事实。
3. 生成待律师确认问题清单。
4. 起草内部法律风险备忘录草稿。
5. 生成客户沟通材料的风险提示。

## 人工复核边界

- 律师或法务负责人确认合同解释和法律风险。
- 销售负责人确认客户沟通口径。
- 管理者确认补救方案、折扣或赔付安排。
- AI 不直接给法律意见、不替代争议处理、不代表任何一方承诺。
