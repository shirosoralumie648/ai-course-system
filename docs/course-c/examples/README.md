# 课程 C 合成样例包

> 本目录全部材料都是合成样例和虚构数据，只用于课堂练习。不要把这里的公司、客户、金额、候选人、合同条款当成真实业务资料。

## 文件清单

| 文件 | 类型 | 可复用周次 | 用途 |
|---|---|---|---|
| [虚构公司画像](/course-c/examples/virtual-company-profile) | Markdown | Week 01-16 | 统一虚拟公司背景 |
| `sample-crm.csv` | CSV | Week 05-06 | 销售线索、CRM 字段、跟进流程 |
| `sample-finance.csv` | CSV | Week 07、Week 10-11 | 经营仪表盘、预算、成本和税务资料准备 |
| `sample-hr.csv` | CSV | Week 12 | 招聘、培训、绩效和公平性检查 |
| [合同纠纷样例](/course-c/examples/sample-contract-dispute) | Markdown | Week 13 | 合同初审、纠纷材料整理和法律风险备忘录草稿 |

## 使用规则

1. 所有数据都必须保留 `sample`、`示例` 或 `虚构` 标记。
2. 学生可以改字段和金额，但不能替换成课堂外部业务对象、人员、合同、税务或凭证数据。
3. 如果课堂需要更真实的材料，先脱敏，再在审计日志里记录处理方式。
4. 高风险任务只做草拟、整理、检查和待确认问题，不给最终专业结论。
