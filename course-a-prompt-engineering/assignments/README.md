# Course A Assignments

## 用途

本目录用于课程 A 阶段作业。MVP 阶段定义可直接采用的作业类型、提交要求和评分重点。

## 作业类型

1. Prompt 改写作业。
2. 专业调研作业。
3. AI 写作修订作业。
4. 数据分析解释作业。
5. 个人 AI 工作流设计作业。

## 提交要求

每份作业必须包含：

- 原始任务。
- 使用的 Prompt。
- AI 输出。
- 人工修订。
- 最终作品。
- 风险与局限。
- 复盘。

## 评分重点

看任务表达是否清楚、上下文是否充分、输出是否经过人工评估和修订。

## 作业发布方式

教师发布作业时，应从上面的作业类型中选择一种，补充专业场景、输入材料、允许使用的 AI 工具、提交格式和评分表。每份作业都必须要求学生提交人工修订记录，避免把 AI 原始输出当作最终作品。
