# 课程 A：AI 思维与 Prompt Engineering 实践

## 课程定位

本课程面向非计算机专业学生，训练他们把 AI 放入专业学习、调研、写作、分析、创意和办公自动化任务中。

课程不是让学生背 Prompt 模板，而是训练：

1. 任务表达。
2. 上下文组织。
3. 结果评估。
4. 人工修订。
5. 风险意识。
6. 专业场景工作流设计。

## 面向对象

文科、商科、管理、教育、新闻传播、设计、医学、法学、外语等专业学生，以及需要提升 AI 使用能力的跨专业学习者。

## 学完能做什么

- 为专业任务设计清晰 Prompt。
- 用 AI 辅助调研、写作、分析和内容创作。
- 评估 AI 输出的可靠性和局限。
- 设计个人 AI 工作流。
- 说明 AI 使用中的版权、伦理和学术诚信风险。
