# Lab 01：Prompt 对比实验

> **完成比完美重要。** 这个实验不要求你写出"完美 Prompt"，只要求你看到好 Prompt 和坏 Prompt 的实际差距。

| 项目 | 内容 |
|---|---|
| **适用周次** | 第 2 周 |
| **预计时长** | 1-1.5 小时 |
| **核心产出** | 原始 Prompt + 改写 Prompt + 两份 AI 输出 + 对比分析 |
| **前置条件** | 能使用任意 AI 工具（ChatGPT、文心一言、通义千问等均可） |

**你将学到：**
- 好 Prompt 和坏 Prompt 的实际输出差距有多大
- Prompt 结构（角色、任务、背景、限制、格式）如何影响 AI 输出质量
- 为什么"让 AI 写得好"需要你先"说清楚"

**实验步骤概览：**

```
① 选一个你专业课的真实任务          ⏱️ ~10min
② 写一个模糊的 Prompt，让 AI 回答    ⏱️ ~10min
③ 用 Prompt 结构改写，再让 AI 回答   ⏱️ ~15min
④ 对比两份输出，分析差异            ⏱️ ~20min
⑤ 写实验记录和复盘                  ⏱️ ~15min
```

---

## 1. 实验任务

选择一个你专业课的真实任务（如写调研提纲、分析案例、解释概念），分别用"模糊 Prompt"和"结构化 Prompt"让 AI 完成，对比输出质量。

## 2. 任务要求

### 第一步：选题

从以下场景中选一个，或自定义一个专业任务：

| 专业方向 | 示例任务 |
|---|---|
| 新闻传播 | 为"大学生心理健康"写一份调研提纲 |
| 商科 | 分析"某奶茶品牌为什么能成功" |
| 教育 | 为"小学三年级数学"设计一个课堂活动 |
| 法学 | 解释"民法典中隐私权的主要内容" |
| 医学 | 为"糖尿病患者"写一份饮食建议 |
| 外语 | 将一段中文商务邮件翻译成英文并润色 |
| 设计 | 为"校园咖啡馆"写一份品牌定位说明 |

### 第二步：写模糊 Prompt

直接用日常语言提问，不要加任何结构。例如：

> 帮我写一个关于大学生心理健康的调研提纲

### 第三步：用结构化 Prompt 改写

按以下结构重写你的 Prompt：

- **角色**：你希望 AI 扮演什么角色？（如"你是有 5 年经验的市场调研员"）
- **任务**：具体要做什么？（如"写一份调研提纲"）
- **背景**：这个任务的背景是什么？（如"针对一线城市大学生"）
- **限制**：有什么不能做或必须做的？（如"不超过 5 个问题""必须包含定量和定性方法"）
- **格式**：输出长什么样？（如"用表格形式，每行一个问题 + 目的 + 方法"）

### 第四步：对比分析

把两份 AI 输出放在一起，从以下维度打分（1-5 分）：

| 维度 | 模糊 Prompt 输出 | 结构化 Prompt 输出 |
|---|---|---|
| 任务完成度 | | |
| 内容准确性 | | |
| 结构清晰度 | | |
| 是否可直接使用 | | |
| 需要人工修订的程度 | | |

### 第五步：写实验记录

## 3. 提交要求

你的实验记录必须包含：

1. **选题说明**：你选了什么任务，为什么选它。
2. **模糊 Prompt 原文**。
3. **结构化 Prompt 原文**。
4. **两份 AI 输出原文**（不要修改，保留原始输出）。
5. **对比分析表**（上表）。
6. **人工修订**：选一份你觉得更好的输出，做人工修订，标注改了什么、为什么改。
7. **复盘**：这次实验让你对 Prompt 有什么新理解？

## 4. 评分标准

| 维度 | 分值 | 说明 |
|---|---|---|
| Prompt 改写质量 | 20 分 | 结构化 Prompt 是否包含角色、任务、背景、限制、格式 |
| 对比分析深度 | 25 分 | 是否从多个维度对比，是否有具体证据支持判断 |
| 人工修订质量 | 25 分 | 修订是否有明确理由，不是随意修改 |
| 复盘反思 | 20 分 | 是否有真实收获，不是套话 |
| 提交完整性 | 10 分 | 7 项提交要求是否齐全 |

## 5. 常见错误

- 只说"结构化 Prompt 更好"，但不分析具体好在哪里。
- 对比时只看长度，不看内容质量。
- 人工修订只是改了格式，没改内容。
- 复盘写"我学到了 Prompt 很重要"，但没有具体收获。

## 6. 参考示例

> **示例选题**：新闻传播专业，任务是"写调研提纲"
>
> **模糊 Prompt**：帮我写一个关于大学生心理健康调研的提纲
>
> **结构化 Prompt**：你是一名有 5 年经验的心理健康调研员。请为一线城市在校大学生设计一份心理健康调研提纲。要求：1）不超过 5 个核心问题；2）必须包含至少 1 个定量问题和 1 个定性问题；3）每个问题说明调研目的和预期发现；4）用表格形式输出。
>
> **预期差异**：模糊 Prompt 可能得到一个泛泛的提纲列表；结构化 Prompt 应该得到有明确目的、方法和预期发现的表格。
