# Prompt Library

## 用途

本目录用于收集课程 A 的 Prompt 示例。MVP 阶段先提供分类、使用原则和筛选标准，避免堆砌未经验证的模板。

## 分类建议

- 调研类 Prompt。
- 写作类 Prompt。
- 数据分析类 Prompt。
- 创意生成类 Prompt。
- 展示汇报类 Prompt。
- 专业场景工作流 Prompt。

## 使用原则

- Prompt 必须包含任务、上下文、限制、输出格式和评价标准。
- Prompt 不能替代人工判断。
- 每个示例必须说明适用场景和风险。
- 不收集未经验证的夸张模板。

## 示例筛选标准

进入 Alpha 试讲后，教师从课堂作业中筛选优秀 Prompt。被收录的示例必须包含原始任务、上下文、输出格式、AI 输出、人工修订记录、适用场景和风险说明；缺少人工修订记录的 Prompt 不进入课程库。
