# Phase 6 Patterns

## Reused Patterns

- Week page 9-section Course C rhythm.
- Lab page 7-section evidence rhythm.
- Source sections split implementation and authoritative domain sources.
- Four-gate compliance checks remain visible.
- Sidebar links only pages that exist.

## Closure Patterns

- Final content should assemble existing artifacts rather than invent new
  business scenarios.
- Final project/rubric edits should be additive and requirement-driven.
- Reference map should use public paths/categories and avoid requiring local
  `reference/repos/` availability.
- Verification evidence should be captured in `06-VERIFICATION.md`.

## Anti-Patterns

- Rewriting existing 01-15 pages unnecessarily.
- Changing approved rubric weights.
- Adding generated build output or local reference clones.
- Treating final defense as a presentation-only task without evidence artifacts.
