# Research Summary: Course C Business AI Operations

## Key Findings

**Stack:** Course C is static curriculum content in the existing VitePress site.
Use Markdown under `docs/course-c/`, update VitePress nav/sidebar, and verify with
`BASE=/ai-course-system/ npm run build` from `docs/`.

**Table stakes:** A usable v1 needs Course C entry pages, all 16 week pages, all
16 lab pages, final project, rubric, reference integration, templates, synthetic
examples, and navigation. Pages must be self-contained for GitHub Pages.

**Differentiators:** Preserve the virtual-company storyline, role-based
assistant pack, workflow transformation evidence, office/SaaS-first path, and
four-gate compliance model.

**Watch out for:** Do not let Course C become a prompt encyclopedia. Do not frame
AI as the final decision maker in investment, HR, tax, finance, legal, or system
operations. Do not introduce live enterprise writes or new cloned reference
dependencies. Avoid prop-heavy VitePress component syntax in the first pass.

## Recommended Roadmap Shape

1. Course C site skeleton and discoverability.
2. Compliance, templates, and synthetic examples foundation.
3. Core business weeks and labs: Weeks 01-07.
4. High-risk business weeks and labs: Weeks 08-14.
5. Enterprise API/MCP workflow week and lab: Week 15.
6. Final project, rubric hardening, reference map, and full verification.
