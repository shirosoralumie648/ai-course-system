# Ethics and Safety

## 用途

本目录用于两门课程共用的伦理、安全、版权和学术诚信材料。

## 核心原则

- 不提交密钥、Token、密码和隐私数据。
- 不伪造资料来源、测试结果或 AI 输出过程。
- 不把 AI 输出直接当作个人理解。
- 不把外部工具输出默认视为可信。
- 涉及真实用户、真实业务或敏感数据时必须脱敏。

## 课程 A 重点

版权、引用、学术诚信、专业判断、AI 输出偏见和错误。

## 课程 B 重点

权限边界、依赖修改、外部服务、MCP 工具调用、代码安全、Human Gate。

## 可直接使用的课堂案例

- 错误引用：学生用 AI 生成参考文献后，必须逐条核验来源是否真实存在。
- Prompt injection：学生把外部文档交给 Agent 前，需要标记外部内容为不可信输入。
- 密钥泄漏：任何截图、日志和提交中出现 API Key、Token、密码或 cookie 都视为高风险问题。
- 测试伪造：Agent 或学生声称“测试通过”时，必须提供可复查的命令、日志和时间点。
