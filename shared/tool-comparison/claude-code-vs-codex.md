# Claude Code 与 Codex 对比

## 对比目的

本文件用于教学对比，帮助学生观察不同 Coding Agent 在代码库理解、计划、修改、权限、测试和总结方面的差异。不要写未经验证的夸张结论。

## Claude Code 适合什么

- 代码库阅读和上下文理解。
- 规则文件驱动的项目任务。
- bugfix、文档和重构前分析。
- 课堂展示 Agent 如何与项目上下文协作。

## Codex 适合什么

- 本地代码修改任务。
- 计划、执行、审批和测试流程训练。
- sandbox 和权限边界教学。
- 小功能修改和可审计 diff 记录。

## 二者共同点

- 都需要清晰任务。
- 都需要项目上下文。
- 都必须审查 diff。
- 都不能替代测试和人工判断。
- 都不能处理密钥和隐私数据。

## 二者差异

| 维度 | Claude Code | Codex |
| --- | --- | --- |
| 教学重点 | 项目上下文、规则文件、代码库协作 | 本地执行、计划、权限、审批 |
| 过程记录 | 适合记录分析和修改过程 | 适合记录计划、命令、diff |
| 风险关注 | 上下文误解、范围扩大 | 权限批准、sandbox、命令边界 |

## 本课程为什么同时讲二者

学生需要学会观察工具行为，而不是迷信单一工具。多工具对比能帮助学生形成 Agentic Development 的通用判断框架。

## 学生如何选择

- 需要深度阅读项目规则和上下文时，可优先考虑 Claude Code。
- 需要训练本地任务执行和权限边界时，可优先考虑 Codex。
- 关键任务应关注流程证据，而不是工具名称。

## 不写未经验证的夸张结论

不要写“某工具一定更强”。所有对比都应来自同一任务、同一项目、同一验收标准下的观察记录。
