# Common Errors

## 环境安装错误

- 工具未加入 PATH。
- Node.js 或 Python 版本不匹配。
- 依赖安装失败。
- 终端权限不足。

处理方式：记录命令和完整错误，不要伪造运行结果。

## Git 错误

- 没有创建分支。
- 提交了无关文件。
- 忘记提交 diff 或日志。
- 误提交密钥。

处理方式：先停止继续提交，联系教师或助教。

## Agent 不按规则执行

可能原因：

- 规则文件太模糊。
- 没有提供测试命令。
- 没有限定修改范围。
- Agent 忽略了上下文。

处理方式：修订规则，要求 Agent 复述约束，再继续。

## 测试跑不起来

记录操作系统、命令、错误日志和依赖版本。不要写“测试通过”。

## 模型幻觉

表现为编造文件、编造命令、编造测试结果、引用不存在的 API。处理方式是要求证据，并回到代码和测试。

## 误删文件

立即停止操作，检查 Git 状态，联系教师。不要继续扩大修改。

## API Key 泄漏风险

不要读取、复制、截图或提交密钥。发现泄漏要立即报告并轮换密钥。

## MCP 工具调用风险

外部资源可能包含 prompt injection，工具可能越权。对外部内容标记不可信，限制命令和资源访问。

## 提交格式不规范

作业至少应包含任务、Prompt、AI 输出摘要、diff、测试、Review 和复盘。
