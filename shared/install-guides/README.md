# 安装指南总览

## 为什么环境准备重要

AI 课程的很多失败并不是来自概念难，而是来自环境不一致。Git、终端、Node.js、Python、Claude Code、Codex、网络和权限问题都会影响实验。

## 学生需要安装什么

- Git。
- 一个代码编辑器，例如 VS Code 或 Cursor。
- Node.js。
- Python。
- Claude Code 或 Codex，按课程实际安排安装。

具体安装命令以官方文档为准。本课程不写未经确认的最新安装命令。

## 教师课前需要检查什么

- 学生能打开终端。
- 学生能运行 Git。
- 学生能 clone 测试仓库。
- 学生能运行 Node.js 或 Python 示例。
- 学生能启动课程要求的 Agent 工具。
- 学生知道不能提交密钥。

## 遇到工具不可用怎么办

- 记录错误截图或日志。
- 先完成文档分析和规则设计部分。
- 使用教师演示环境观察流程。
- 不要伪造工具运行结果。

## 推荐最低环境

- 现代 Windows 10/11 或 macOS。
- 稳定网络。
- Git 可用。
- Node.js 和 Python 至少有一个可用。
- 能访问课程指定工具。
