# Git 与 GitHub 基础

## Git 基本概念

- repository：代码仓库。
- commit：一次可追溯的修改记录。
- branch：并行开发分支。
- diff：修改前后的差异。
- pull request：请求合并并接受 Review 的流程。

## clone

从远程仓库复制项目到本地。课程中不要 clone 来源不明的仓库。

## branch

每次实验建议创建单独分支，例如 `lab-01-bugfix`。

## commit

提交前先看 `git diff`。commit 信息应简短说明修改目的。

## diff

实验中必须提交或截图 diff。diff 是审查 Agent 修改的核心证据。

## pull request

期末项目建议用 PR 方式展示修改、测试和 Review。

## 如何提交实验作业

- 提交仓库链接或压缩包。
- 提交实验记录 Markdown。
- 提交测试日志。
- 提交 diff 或 PR 链接。
- 提交复盘。

## 不要提交密钥

不要提交 `.env`、Token、密码、私钥、cookie 和真实用户数据。发现误提交要立即报告教师。
