# Codex CLI 安装与验证说明

## 重要说明

Codex CLI 的安装命令、登录方式、模型可用性和权限策略可能变化。本课程不写未经确认的最新安装命令。请以官方文档为准。

## 课程要求的验证能力

学生完成安装后，需要验证：

1. 能在本地项目目录中启动 Codex。
2. 能读取项目文件。
3. 能生成修改计划。
4. 能按任务修改文件。
5. 能运行教师指定测试。
6. 能输出 diff 和总结。
7. 能识别 sandbox、approval 或权限边界。

## 常见问题

- 登录或授权失败。
- 模型不可用。
- 网络不可用。
- 终端环境不兼容。
- 权限或 sandbox 限制导致命令不能执行。

## 安全要求

不要在 Prompt、日志、截图或提交中暴露 API Key、Token、密码或隐私数据。不要批准不理解的危险操作。
