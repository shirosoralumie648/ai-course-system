# Node.js 与 Python 环境说明

## 用途

课程示例项目可能使用 JavaScript 或 Python。学生至少应能运行其中一种技术栈的示例项目。

## Node.js

以官方文档为准安装。学生需要验证：

- 能运行 `node`。
- 能运行 `npm`。
- 能在教师提供项目中安装依赖和运行测试。

## Python

以官方文档或学校推荐方式安装。学生需要验证：

- 能运行 `python` 或 `python3`。
- 能创建或使用课程指定环境。
- 能运行教师提供的测试。

## 环境记录

作业中如果出现环境问题，应记录：

- 操作系统。
- Node.js 或 Python 版本。
- 执行的命令。
- 完整错误日志。

## 安全提醒

不要复制来源不明的一键安装脚本。不要在环境变量截图中暴露密钥。
