# Windows 安装提示

## Git 安装

从 Git 官方网站下载安装包。安装后在 PowerShell、Windows Terminal 或 Git Bash 中验证 Git 可用。不要在提交中包含账号密码或 Token。

## VS Code 或 Cursor

任选一个代码编辑器。教师应提前说明课堂演示使用哪个工具，避免学生在工具差异上浪费时间。

## Node.js

以 Node.js 官方网站为准安装。安装后验证 `node` 和 `npm` 可用。不要复制来源不明的安装脚本。

## Python

以 Python 官方网站或学校推荐方式安装。注意勾选 PATH 相关选项，或按官方说明配置。

## 终端使用建议

建议使用 Windows Terminal 或 PowerShell。路径中尽量避免过长路径和特殊字符。

## 常见权限问题

- 无法执行脚本。
- 目录无写入权限。
- 杀毒软件拦截工具。
- 终端没有管理员权限。

遇到权限问题时先截图和记录错误，不要随意关闭系统安全设置。

## 路径和中文目录注意事项

课程示例项目建议放在英文路径，例如 `C:\courses\ai-course\`。部分工具在中文路径或空格路径下可能表现不一致。

## 代理和网络问题提示

如果工具登录或模型不可用，记录错误，联系教师。不要把代理账号、Token 或 cookie 写入作业。

## 不要写真实密钥

任何 API Key、Token、密码、cookie、私钥都不能写入代码、截图、日志或提交。
