# Claude Code 安装与验证说明

## 重要说明

Claude Code 的安装、登录和可用模型可能随官方产品变化。本课程不在此写未经确认的最新安装命令。请以官方文档为准。

## 课程要求的验证能力

学生完成安装后，需要截图或记录以下能力：

1. 能在项目目录中启动 Claude Code。
2. 能让工具读取项目结构。
3. 能让工具生成任务计划。
4. 能在允许范围内修改文件。
5. 能运行测试或说明不能运行的原因。
6. 能输出 diff 摘要。

## 常见问题

- 登录失败。
- 模型不可用。
- 网络不可用。
- 终端环境问题。
- 权限不足。
- 项目路径包含特殊字符导致工具异常。

## 安全要求

不要把账号、Token、cookie、API Key 或隐私信息贴给 Agent。涉及外部服务访问时必须先获得教师或人工审批。
