# macOS 安装提示

## Homebrew 可选

Homebrew 可以帮助安装开发工具，但不是课程唯一要求。是否使用以学校环境和教师安排为准。

## Git

可通过 Xcode Command Line Tools、Homebrew 或官方方式安装。验证 Git 可用后再开始实验。

## Node.js

以 Node.js 官方文档为准。安装后验证 `node` 和 `npm` 可用。

## Python

以 Python 官方文档或学校推荐方式安装。注意区分系统 Python 和课程使用的 Python。

## 终端

可以使用 Terminal、iTerm2 或编辑器内置终端。建议统一项目目录，避免路径混乱。

## 权限问题

常见问题包括终端无权限访问目录、脚本无执行权限、系统安全弹窗阻止运行。遇到问题先记录错误，不要随意执行来源不明的修复命令。

## 常见错误

- `command not found`：工具未安装或 PATH 未配置。
- 依赖安装失败：网络、版本或权限问题。
- Agent 工具无法登录：账号、网络或模型权限问题。

## 安全提醒

不要把真实 API Key、Token、密码写入终端截图或作业。
